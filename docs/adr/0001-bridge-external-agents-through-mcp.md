# 通过本机 MCP 桥接外部 Agent 与活动画布

外部 Agent 通过受认证的本机 MCP 边界请求当前活动项目；前端画布控制层读取或执行受限操作，Codex 是首个验收客户端。外部访问启用后，前端仍依据当前项目、revision、`nodeRegistry` 能力白名单和既有连线规则重新校验每个变更。通过校验的 `CanvasChangeSet` 由应用服务原子执行，并生成一个历史检查点供整批撤销。

协议 v2 在同一工具层增加受控动作：通过既有图片管线批量导入参考图、运行已存在的 `imageNode`，以及按明确节点 ID 返回压缩结果预览。该边界不允许任意创建节点、删除、直接写媒体字段或未授权的计费操作。

本 ADR 已由 ADR-0003 取代。桥接交付与协议约束以 ADR-0003 为准；长期项目和资产归属以 ADR-0006 为准。
