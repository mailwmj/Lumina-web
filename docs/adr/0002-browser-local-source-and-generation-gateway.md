# 受限生成网关与浏览器客户端边界

> **状态（2026-08-25）**：ADR-0006 已定义持久项目、历史和资产的 Runtime-first 归属。本 ADR 仅保留仍有效的 GenerationGateway 安全、保留期和生成任务恢复决策；浏览器设置迁移另行设计。

Web 运行时通过窄边界组织：`ProjectRepository` 负责项目聚合，`AssetRepository` 负责长期资产，`SettingsRepository` 负责偏好和供应商配置，`GenerationGateway` 负责生成任务，`MediaProcessor` 负责媒体变换。项目仓库不得序列化 Blob 或凭据；长期项目与资产事实的所有权以 ADR-0006 为准。

与页面同 Origin 的生成网关只代理 Lumina 审核过的供应商域名，可按 TTL 短期保存完成请求所必需的任务映射、公开媒体副本和转码结果，但不拥有项目数据。自定义 `base_url` 由浏览器直接访问；不支持 CORS 时由用户部署自己的网关，官方服务不提供匿名任意地址代理，以避免 SSRF 和开放代理风险。

生成网关不引入完整账户系统。页面使用短期同源会话，网关按会话和来源限制频率与并发，并按操作和供应商设置请求体上限；公开 Beta 的成本无法受控时使用邀请码限制访问。输入媒体、转码文件和结果缓存最长保留 24 小时，浏览器确认结果持久化后保留 1 小时安全窗口再删除；活动任务映射按供应商期限保留且不超过 7 天，终态映射再保留 24 小时。

网关日志只保留请求 ID、操作类型、供应商标识、状态码、耗时和字节数，默认保存 7 天。API Key、授权头、提示词、媒体、base64、完整 URL、完整上游响应和桥接凭据不得进入日志；可读的原始供应商错误只返回当前浏览器，不持久化响应体。

只有具有稳定供应商任务 ID 的生成任务才能在刷新后恢复；持久化任务 handle 时只查询原任务。无法恢复的任务在刷新后标记为中断，任何恢复流程都不得自动重新提交可能计费的请求。

生成网关任务状态和临时生成介质是短期运行事实，绝不成为项目、画布、历史或长期资产。Object URL 仅是展示租约，不得被持久化为项目事实。
