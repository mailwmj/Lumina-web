# 浏览器本地事实源与受限生成网关

Lumina 当前仓库以 `v0.2.37`（`77e6d1e`）为功能等价基线整体迁移为 Web 产品；项目、画布、历史和长期资产只由固定生产 Origin 下的浏览器持有，不在服务端建立项目数据库，也不迁移桌面版 SQLite 数据。公开 Web Beta 起必须通过版本化 schema migration 保持 Web 数据可读，普通项目或配置导出永不包含 API Key、WebDAV 密码等凭据。

Web 运行时通过五个窄边界组织：`ProjectRepository` 负责项目聚合，`AssetRepository` 负责长期 Blob，`SettingsRepository` 负责偏好、供应商配置和浏览器本地凭据，`GenerationGateway` 负责生成任务，`MediaProcessor` 负责媒体变换。已有更窄的模型、文本和图片处理接口可以保留为内部实现，不把这些职责合并成一个通用运行时接口；项目仓库不得序列化 Blob 或凭据。

与页面同 Origin 的生成网关只代理 Lumina 审核过的供应商域名，可按 TTL 短期保存完成请求所必需的任务映射、公开媒体副本和转码结果，但不拥有项目数据。自定义 `base_url` 由浏览器直接访问；不支持 CORS 时由用户部署自己的网关，官方服务不提供匿名任意地址代理，以避免 SSRF 和开放代理风险。

生成网关首期不引入完整账户系统。页面使用短期同源会话，网关按会话和来源限制频率与并发，并按操作和供应商设置请求体上限；公开 Beta 的成本无法受控时使用邀请码限制访问。输入媒体、转码文件和结果缓存最长保留 24 小时，浏览器确认结果落库后保留 1 小时安全窗口再删除；活动任务映射按供应商期限保留且不超过 7 天，终态映射再保留 24 小时。

网关日志只保留请求 ID、操作类型、供应商标识、状态码、耗时和字节数，默认保存 7 天。API Key、授权头、提示词、媒体、base64、完整 URL、完整上游响应和桥接凭据不得进入日志；可读的原始供应商错误只返回当前浏览器，不持久化响应体。

迁移在当前仓库中渐进完成：先以窄接口隔离现有 Tauri 能力，再逐项接入浏览器或生成网关实现，通过功能等价验证后删除本分支对应的 Tauri 代码。图片裁剪、标注、拼图和分镜合成优先在浏览器执行；音视频转码、临时公网媒体和浏览器不稳定支持的编码由生成网关处理，完成结果回写为浏览器资产。

生成结果默认作为浏览器资产保存；本机输出通过浏览器下载，或在用户授权后通过 File System Access 写入指定目录，并始终提供 ZIP 下载兜底。浏览器资产采用基于当前项目、保留历史、未完成任务和资产库的标记清扫，不以可变引用计数作为唯一删除依据。

只有具有稳定供应商任务 ID 的生成任务才能在刷新后恢复；浏览器持久化任务 handle，并且只查询原任务。无法恢复的任务在刷新后标记为中断，任何恢复流程都不得自动重新提交可能计费的请求。

撤销能力在迁移期保持当前产品基线：活动会话最多 50 步，跨重载最多恢复最近 12 步。实现应按完整快照逐步保留，不得因历史总 JSON 超过固定字符数而静默放弃全部历史；资产在快照中只以稳定 `assetId` 引用。

首个正式版本支持当前两个主版本的 Chrome、Edge 和对应的 Codex 内置 Chromium。项目在多个标签页中采用单写者模型；断网时仍可编辑已有项目和浏览器资产，但生成、远端结果回收、生成网关和 Codex 桥接需要联网。

仓库维护以功能等价基线为行、以 Web 实现、自动测试、浏览器手测和异常路径证据为列的等价矩阵。Beta 可以明确暴露未完成项；只有矩阵全部通过并经产品确认后，版本才可称为完整 Web 替代。
