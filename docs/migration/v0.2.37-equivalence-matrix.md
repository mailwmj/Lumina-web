## 运行时组合壳

`src/runtime/runtime.ts` 是唯一的 Tauri/Web 组合边界。业务层通过 `runtime` 使用启动通知、
版本、目录选择、打开链接和命令调用；Web 模式只实现不需要原生能力的项目记录命令，其他命令
会以明确的“不支持”错误失败，不伪造 Tauri 能力。Tauri 模式继续调用既有命令，因此桌面路径
的用户可见行为不变。

## 证据规则

1. 自动测试必须能在移除实现后失败，不能只检查模块是否可导入。
2. 手测证据记录浏览器、视口、语言/主题和主路径截图或录屏位置。
3. 异常路径证据记录输入、可见错误、状态恢复结果和是否产生副作用。
4. 发布前，任何仍标记“待补”的行都阻塞“功能等价”结论；本矩阵作为迁移进度基线，具体闭环由对应迁移票实现。
