# 服装模特图批量裁剪产品设计文档

## 1. 项目背景

### 1.1 需求简介

#### 1.1.1 核心需求

- 摄影师交付的服装模特原图通常为单张 20MB 至 40MB。
- 用户需要把最多 100 张原图批量裁剪并缩放为电商平台要求的固定尺寸。
- 系统需要在本地自动计算每张图片的默认裁剪区域。
- 用户只需要检查高风险图片，并对不满意的区域进行手动调整。
- 系统需要把确认后的图片统一导出为高质量 JPG 文件。

### 1.2 业务诉求

#### 1.2.1 当前问题

- 用户逐张设置比例、调整裁剪区域和导出文件，操作重复。
- 摄影师交付的原图已经表达目标画面，尺寸适配应尽量保留原构图，只舍弃目标比例要求下不可避免的边缘区域。
- 大图批量载入时容易出现等待时间长、页面卡顿和处理进度不透明的问题。
- 云端处理会增加原图泄露风险，不满足本次需求。

#### 1.2.2 预期结果

- 用户完成尺寸选择和批量上传后，可以一次生成整批裁剪方案。
- 普通图片直接采用系统方案，高风险图片由用户重点检查。
- 用户确认后可以一次完成整批裁剪、缩放和本地导出。
- 原图和处理中间数据全程留在本地。

### 1.3 目标用户

#### 1.3.1 主要用户

- 需要整理服装模特商品图的电商设计人员。
- 需要批量交付平台尺寸图片的摄影后期人员。
- 需要快速检查和修正裁剪区域的运营人员。

### 1.4 默认假设

#### 1.4.1 首版假设

- DA-1：目标尺寸固定为“1440 × 1440”“1440 × 1920”“1440 × 2200”。
- DA-2：用户每次任务只能选择一种目标尺寸。
- DA-3：每批最多添加 100 张图片。
- DA-4：首版支持 JPG、JPEG、PNG；不支持相机 RAW、HEIC、GIF 和动态图片。
- DA-5：首版验收范围覆盖单张不超过 60MB 的图片。
- DA-6：首版默认摄影师已经完成有效构图，不使用主体识别结果重新安排画面。
- DA-7：图片分析、裁剪、缩放和结果生成全程在本地完成。
- DA-8：首版不保存裁剪任务；用户退出裁剪工作台后不能恢复本次进度。
- DA-9：输出统一为 JPG，质量固定为 100，不提供质量设置。
- DA-10：输出文件不覆盖原图，也不覆盖导出目录中的同名文件。
- DA-11：系统不强制用户逐张打开普通图片，只强制处理“需检查”图片。
- DA-12：图片列表和裁剪编辑区只使用缩略图或清晰预览图，不把原图作为界面展示资源。
- DA-13：首版必须在 8GB 内存、无独立显卡的设备上完成整批任务。
- DA-14：图片方向校正提供向左和向右旋转 90°，用户可连续点击完成 180°校正。
- DA-15：为避免低配置设备解码超大像素图片时耗尽内存，首版不处理超过 1.2 亿像素的单张图片。

## 2. 范围

### 2.1 本期包含

#### 2.1.1 功能范围

- 首页新增“图片裁剪”入口。
- 提供三个固定目标尺寸。
- 支持选择文件和拖拽方式批量添加图片。
- 支持最多 100 张图片的缩略图列表。
- 在本地为每张图片生成默认裁剪区域。
- 对目标比例导致原画面保留面积低于 80% 的图片标记“需检查”。
- 支持逐张查看、移动和缩放固定比例裁剪框。
- 支持恢复单张图片的自动裁剪区域。
- 支持按 90°步进校正单张图片方向。
- 支持选择本地文件夹后批量裁剪、缩放并直接导出 JPG。
- 支持导出部分失败展示和失败项重试。
- 支持未导出退出提醒。
- 支持中英文界面。

### 2.2 本期不包含

#### 2.2.1 排除范围

- 不接入云端分析、云端存储或云端裁剪服务。
- 不支持自定义宽度和高度。
- 不支持一批图片同时导出多个尺寸。
- 不支持相机 RAW 文件处理。
- 不支持背景填充、扩图、抠图、背景替换和美化。
- 不支持自由角度旋转、透视矫正、颜色调整和图片压缩参数设置。
- 不支持多人图片中的人物选择。
- 不集成人体、服装或多人检测模型。
- 不支持把裁剪结果写入 Lumina 画布项目。
- 不支持保存草稿和重启后恢复任务。
- 不支持覆盖原文件。

### 2.3 后续候选

#### 2.3.1 延后评估

- 同一批图片一次导出多个目标尺寸。
- 自定义尺寸和常用尺寸收藏。
- 支持 HEIC 和相机 RAW 文件。
- 支持任务保存、历史记录和继续处理。
- 支持同组图片复用构图规则。
- 支持多人图片选择主模特。
- 支持文件夹批量导入。

## 3. 用户场景

### 3.1 正常路径

#### 3.1.1 创建裁剪任务

- GIVEN 用户位于软件首页，WHEN 用户点击“图片裁剪”，THEN 系统进入独立的图片裁剪工作台。
- GIVEN 用户尚未选择目标尺寸，WHEN 页面完成加载，THEN 上传入口保持不可用，不额外展示操作提示。
- GIVEN 用户已选择目标尺寸，WHEN 用户添加有效图片，THEN 系统按选择顺序展示图片列表。

#### 3.1.2 生成裁剪方案

- GIVEN 用户已选择目标尺寸，WHEN 用户添加有效图片并完成清晰预览生成，THEN 系统在同一轮本地处理内自动计算默认裁剪区域并展示进度。
- GIVEN 目标比例可以保留至少 80% 的原画面，WHEN 系统完成计算，THEN 图片状态变为“自动完成”。
- GIVEN 目标比例只能保留不足 80% 的原画面，WHEN 系统完成计算，THEN 图片状态变为“需检查”。

#### 3.1.3 检查和调整

- GIVEN 图片已有裁剪方案，WHEN 用户选中缩略图，THEN 右侧展示该图片、文件名和固定比例裁剪框。
- GIVEN 用户不满意裁剪区域，WHEN 用户移动或缩放裁剪框，THEN 系统实时更新预览并把图片标记为“已手动调整”。
- GIVEN 图片显示方向错误，WHEN 用户点击向左或向右旋转，THEN 系统把当前图片旋转 90°并更新预览方向。
- GIVEN 图片状态为“需检查”，WHEN 用户完成调整或点击“确认当前”，THEN 图片状态变为“已确认”。

#### 3.1.4 裁剪和导出

- GIVEN 所有必检图片均已确认，WHEN 用户点击“确认并导出”，THEN 系统打开本地目录选择器。
- GIVEN 用户确认导出目录，WHEN 系统开始处理，THEN 系统按当前方案逐张读取原图、裁剪、缩放并直接写入目录。
- GIVEN 全部结果导出成功，WHEN 导出结束，THEN 系统展示成功数量、导出目录和“添加新批次”按钮；用户点击“确认”时保留当前结果，点击“添加新批次”时清除本批已导出图片及其本地预览缓存，并保留当前裁剪尺寸以继续添加图片。

### 3.2 异常与边界

#### 3.2.1 导入异常

- GIVEN 用户一次选择超过剩余数量上限的图片，WHEN 系统读取选择结果，THEN 系统只添加上限内的图片并提示未添加数量。
- GIVEN 文件格式不支持、文件损坏或单张超过 60MB，WHEN 系统读取文件，THEN 系统跳过该文件并展示具体原因。
- GIVEN 用户重复添加同一路径的文件，WHEN 系统检查列表，THEN 系统跳过重复文件并保留首次添加项。

#### 3.2.2 默认裁剪异常

- GIVEN 目标比例会舍弃 20% 或以上原画面，WHEN 自动计算结束，THEN 系统生成最大居中裁剪区域并标记“需检查”。
- GIVEN 某张图片计算过程异常，WHEN 批量计算继续，THEN 系统为该图片生成居中比例裁剪并标记“需检查”。

#### 3.2.3 裁剪与导出异常

- GIVEN 原图在任务期间被移动、删除或失去读取权限，WHEN 系统开始裁剪，THEN 该图片处理失败并提示“找不到原图，请重新添加”。
- GIVEN 部分图片裁剪失败，WHEN 批量处理结束，THEN 成功项保持完成，失败项可单独重试。
- GIVEN 导出目录不可写或空间不足，WHEN 用户开始导出，THEN 系统停止写入当前失败文件并保留其他已成功文件。
- GIVEN 导出目录存在同名文件，WHEN 系统写入结果，THEN 系统生成不重复的新文件名，不覆盖已有文件。

### 3.3 状态变化

#### 3.3.1 图片状态

- GIVEN 图片因更换裁剪尺寸而需要重新计算，WHEN 尚未生成方案，THEN 状态为“待生成”。
- GIVEN 系统正在计算裁剪区域，WHEN 任务未结束，THEN 状态为“计算中”。
- GIVEN 系统生成普通方案，WHEN 不存在明显风险，THEN 状态为“自动完成”。
- GIVEN 系统发现风险，WHEN 用户尚未处理，THEN 状态为“需检查”。
- GIVEN 用户修改裁剪区域，WHEN 修改完成，THEN 状态为“已手动调整”。
- GIVEN 用户确认风险图片，WHEN 确认完成，THEN 状态为“已确认”。
- GIVEN 图片正在生成结果，WHEN 处理未结束，THEN 状态为“裁剪中”。
- GIVEN 图片导出成功，WHEN 文件写入完成，THEN 状态为“已导出”。
- GIVEN 任一步骤失败，WHEN 系统记录失败原因，THEN 状态为“处理失败”。

#### 3.3.2 方案失效

- GIVEN 图片已有裁剪方案，WHEN 用户更换目标尺寸并确认，THEN 全部旧方案和未导出结果失效，图片重新进入“待生成”。
- GIVEN 图片已导出，WHEN 用户再次修改该图片的裁剪框，THEN 仅该图片导出状态失效并进入“已手动调整”。
- GIVEN 图片已有裁剪方案或结果，WHEN 用户旋转该图片并完成新的清晰预览生成，THEN 仅该图片的旧方案和结果失效，并立即获得按新方向计算的默认裁剪方案。

## 4. 需求清单

### 4.1 功能需求

#### 4.1.1 入口与任务

- FR-1：系统 MUST 在首页“新建项目”按钮左侧展示“图片裁剪”入口。
- FR-2：系统 MUST 通过独立工作台承载裁剪任务，不创建画布项目。
- FR-3：系统 MUST 在用户存在未导出内容时提供退出确认。

#### 4.1.2 尺寸与导入

- FR-4：系统 MUST 要求用户先选择目标尺寸，再允许添加图片。
- FR-5：系统 MUST 提供“1440 × 1440”“1440 × 1920”“1440 × 2200”三个固定尺寸。
- FR-6：系统 MUST 支持单次任务最多添加 100 张图片。
- FR-7：系统 MUST 支持 JPG、JPEG、PNG 图片，并展示格式、大小和读取失败原因。
- FR-8：系统 MUST 支持追加图片、移除图片和跳过重复图片。

#### 4.1.3 自动裁剪与复核

- FR-9：系统 MUST 在每张图片的清晰预览生成完成后，自动在本地计算符合目标比例的默认裁剪区域。
- FR-10：系统 MUST 默认保留原图构图，在目标比例下生成面积最大的居中裁剪区域。
- FR-11：系统 MUST 在默认区域只能保留不足 80% 原画面时标记“需检查”，不得依赖主体识别改变原构图。
- FR-12：系统 MUST 展示逐张计算进度和每张图片的当前状态。
- FR-13：系统 MUST 支持移动和缩放固定比例裁剪框。
- FR-14：系统 MUST 支持单张恢复自动裁剪区域。
- FR-15：系统 MUST 阻止用户在未确认“需检查”图片时开始批量裁剪。

#### 4.1.4 结果与导出

- FR-16：系统 MUST 按用户确认区域裁剪原图，并缩放为精确目标像素。
- FR-17：系统 MUST 统一生成质量为 100 的 JPG 文件。
- FR-18：系统 MUST 使用“原文件名_宽x高.jpg”规则生成输出名称。
- FR-19：系统 MUST 在用户点击“确认并导出”后选择本地目录，并在确认目录后连续完成裁剪、缩放和写入。
- FR-20：系统 MUST 在导出部分失败时保留成功项，并允许用户通过“重试失败项”再次选择目录后重试。
- FR-21：系统 MUST 不修改原图，不覆盖导出目录中的同名文件。
- FR-22：系统 MUST 在用户修改已处理图片后，只使对应图片的旧结果失效。

#### 4.1.5 隐私与语言

- FR-23：系统 MUST 在裁剪任务全流程中不上传原图、预览图、裁剪参数和输出文件。
- FR-24：系统 MUST 为新增页面文案提供完整的中文和英文版本。

#### 4.1.6 方向校正

- FR-25：系统 MUST 支持用户把当前图片向左或向右旋转 90°，并允许连续操作完成 180°校正。
- FR-26：系统 MUST 在图片旋转后使该图片已有裁剪方案和未导出结果失效，不得影响其他图片。
- FR-27：系统 MUST 以用户在编辑区确认的图片方向生成最终结果。
- FR-28：系统 MUST 在全部导出成功的完成弹窗中提供“添加新批次”操作；该操作才可清除本批已导出图片和本地预览缓存，“确认”和关闭弹窗不得清除结果。
- FR-29：系统 MUST 在右侧图片编辑区支持左右方向键切换上一张和下一张；输入控件、裁剪拖动操作和弹窗打开时不得劫持方向键。

### 4.2 非功能需求

#### 4.2.1 性能与稳定性

- NFR-1：系统 MUST 支持 100 张、单张不超过 60MB 的有效图片完成同一批任务。
- NFR-2：系统 MUST 在批量计算、裁剪和导出期间保持列表滚动、图片切换和退出操作可响应。
- NFR-3：系统 MUST 按需加载列表缩略图，不得同时加载全部列表图片的清晰预览或原图。
- NFR-4：系统 MUST 在裁剪编辑区只加载当前图片的清晰预览图，不得加载原图作为编辑图。
- NFR-5：系统 MUST 使用清晰预览图完成自动构图、区域展示和手动调整，裁剪区域必须能够准确映射回原图。
- NFR-6：系统 MUST 在生成预览图和最终结果时按实际资源占用限制处理数量，任一阶段同时处理的原图不得超过 2 张。
- NFR-7：系统 MUST 在单张预览或结果生成完成后立即释放原图解码数据，不得让整批原图同时驻留内存。
- NFR-8：系统 MUST 在 8GB 内存、无独立显卡的设备上仅使用 CPU 完成导入、自动裁剪、调整和导出。
- NFR-9：系统 MUST 在每张图片完成或失败后立即更新进度，不允许长时间只展示无明确信息的加载状态。

#### 4.2.2 质量与安全

- NFR-10：系统 MUST 保证所有输出图片的宽高像素与用户选择的目标尺寸完全一致。
- NFR-11：系统 MUST 保证输出图片不发生非等比拉伸。
- NFR-12：系统 MUST 根据图片可见方向进行裁剪，避免导出结果旋转错误。
- NFR-13：系统 MUST 在目标比例会舍弃 20% 或以上原画面时明确标记风险。
- NFR-14：系统 MUST 仅访问用户主动选择的图片和导出目录。

#### 4.2.3 一致性与可用性

- NFR-15：系统 MUST 复用 Lumina 的主题、按钮、选择器、弹窗、提示和图标规范。
- NFR-16：系统 MUST 在明暗主题下保证裁剪框、遮罩、状态和错误信息可辨识。
- NFR-17：系统 MUST 在中英文切换后不展示未翻译键，按钮和状态文案不得被截断。

## 5. 关键决策

| 决策 | 选择 | 理由 | 否决方案 |
| --- | --- | --- | --- |
| 首页入口 | 放在“新建项目”左侧 | 符合用户指定位置，并与项目创建保持同级 | 放入画布工具栏或设置页 |
| 产品形态 | 独立裁剪工作台 | 任务以批处理为主，不需要画布节点和项目结构 | 为每张图片创建画布节点 |
| 使用顺序 | 先选尺寸，再添加图片 | 从导入开始即可确定预览比例和处理规则 | 上传后再选择尺寸 |
| 每批尺寸 | 一批只选一种尺寸 | 降低列表状态和导出命名复杂度 | 一张图片同时选择多个尺寸 |
| 自动裁剪方式 | 最大面积居中裁剪 | 原图已完成构图，仅舍弃目标比例要求下不可避免的边缘区域 | 主体识别后重新构图或云端识别 |
| 风险处理 | 按画面保留比例标记并强制检查风险项 | 只关注目标比例造成的实际画面损失，不引入主体识别误判 | 判断失败后阻断整批任务 |
| 复核方式 | 缩略图列表加单图编辑区 | 100 张大图不适合同时在主区域展开 | 主区域纵向展示全部原图 |
| 确认规则 | 只强制确认“需检查”图片 | 保留自动化效率，同时控制高风险结果 | 强制逐张打开确认或完全不确认 |
| 输出目录 | 点击“确认并导出”后再选择文件夹 | 不占用图片列表空间，目录选择只在需要生成文件时出现 | 在左侧栏常驻导出文件夹字段 |
| 输出格式 | 固定高质量 JPG，质量 100 | 本期以尽量保留画质为最高优先级 | JPG 90、JPG 95、跟随原格式或让用户配置质量 |
| 同名文件 | 自动增加序号，不覆盖 | 避免误删已有交付文件 | 直接覆盖或阻止整批导出 |
| 任务保存 | 首版不保存，退出前提醒 | 控制首版范围，同时避免用户误丢未导出结果 | 自动保存任务和跨重启恢复 |
| 隐私边界 | 全程本地处理 | 用户已明确要求，且原图文件较大 | 上传云端识别或转码 |
| 编辑图来源 | 使用清晰预览图 | 编辑只需要确认构图，原图不进入界面可显著降低内存占用 | 在裁剪编辑区直接加载原图 |
| 批量资源策略 | 按需缩略图、单图预览、原图最多小并发 2 张 | 适配 8GB 内存且无独立显卡的设备 | 整批预加载、全量原图常驻或依赖独立显卡 |
| 图片方向校正 | 向左和向右旋转 90° | 覆盖常见方向错误，减少多次点击，坐标映射明确 | 自由角度旋转或依赖用户重新处理原图 |

## 6. 公共规则

### 6.1 日期与时间规则

#### 6.1.1 本期规则

- 本功能不按日期归属任务，不展示任务日期。
- 导出文件名不增加日期和时间。
- 错误日志如需展示时间，使用当前系统本地时间。

### 6.2 数值与单位规则

#### 6.2.1 尺寸

- 页面尺寸统一展示为“宽 × 高”，单位为像素。
- 文件名尺寸统一使用半角字母“x”，例如“1440x1920”。
- 裁剪框比例始终等于所选目标尺寸比例。

#### 6.2.2 文件大小与数量

- 文件大小小于 1MB 时展示到 0.1MB，大于或等于 1MB 时展示到 1MB。
- 图片数量统一展示为“已添加数量/100”。
- 进度统一展示为“已完成数量/总数量”。

### 6.3 数据刷新规则

#### 6.3.1 操作结果

- 【添加图片成功】 -> 【刷新缩略图列表、数量和主预览】。
- 【移除图片成功】 -> 【刷新缩略图列表、数量和当前选择】。
- 【自动计算完成一张】 -> 【刷新该图片状态、总体进度和裁剪预览】。
- 【手动调整完成】 -> 【刷新该图片状态和裁剪参数】。
- 【导出完成一张】 -> 【刷新该图片状态、成功数量和失败数量】。
- 【失败项重试成功】 -> 【刷新该图片状态和批次汇总】。

### 6.4 可操作范围规则

#### 6.4.1 按钮状态

- 未选择尺寸时，“添加图片”置灰。
- 列表为空时，“生成裁剪方案”置灰。
- 不存在“待生成”图片时，不显示可点击的“生成裁剪方案”。
- 批量计算期间，尺寸选择、添加图片和移除图片置灰。
- 存在未确认的“需检查”图片时，“确认并导出”置灰。
- 存在“待生成”“计算中”或无法读取原图的图片时，“确认并导出”置灰。
- 批量导出期间，“确认并导出”和“再次导出”置灰。
- 所有图片均已导出时，主按钮显示“再次导出”。

### 6.5 数据归属与冲突规则

#### 6.5.1 数据来源

- 原图以用户选择的本地文件为准。
- 当前裁剪区域以单张图片最近一次自动计算或手动调整结果为准。
- 当前图片方向以原图可见方向叠加用户最近一次旋转结果为准。
- 手动调整优先于自动裁剪区域。
- 输出结果以用户确认导出目录时的裁剪区域为准。
- 导出目录以用户本次点击“确认并导出”或“再次导出”后确认选择的本地文件夹为准。

#### 6.5.2 追加与覆盖

- 再次添加图片采用追加规则，不清空已有图片。
- 同一路径文件重复添加时跳过，不新增重复项。
- 更换目标尺寸会使整批裁剪区域和未导出结果失效。
- 修改单张已处理图片，只使该图片结果失效。
- 旋转单张图片只使该图片的裁剪区域和未导出结果失效。
- 再次导出不覆盖已有文件，系统为新文件增加序号。

### 6.6 排序与选择规则

#### 6.6.1 列表顺序

- 图片默认按用户选择文件时的返回顺序排列。
- 追加图片排在已有图片之后。
- 处理状态变化不改变图片顺序。
- 首次添加成功后默认选中第一张有效图片。
- 删除当前图片后优先选中下一张；没有下一张时选中上一张。

### 7.3 图片添加与列表

#### 7.3.1 添加方式

- 用户可以把图片拖入左侧添加区域。
- 文件选择器允许一次选择多张图片。

#### 7.3.2 输入限制

- 支持扩展名：.jpg、.jpeg、.png。
- 单张文件大小不得超过 60MB。
- 单张图片总像素不得超过 1.2 亿像素。
- 单批有效图片总数不得超过 100 张。
- 不支持的文件不进入任务列表。

#### 7.3.3 列表项展示

- 展示图片缩略图。
- 展示原文件名，超出宽度时单行截断，悬停显示完整名称。
- 展示当前状态。
- “需检查”和“处理失败”使用高于普通状态的视觉提示。
- 当前图片显示选中边框。
- 列表支持滚动，不分页。

#### 7.3.4 空态与反馈

- 列表为空时不展示额外提示文案。
- 文件读取、清晰预览和默认裁剪方案生成期间，系统展示总体进度。
- 添加完成后提示“已添加 n 张图片”。
- 部分文件未添加时提示“已添加 n 张，m 张未添加”，并允许展开查看原因。

#### 7.3.5 交互流程

- 【点击列表项】 -> 【主区域切换到对应图片】。
- 【点击列表项删除图标】 -> 【从当前任务移除该图片】。
- 【追加有效图片】 -> 【新图片按选择顺序排在列表末尾；清晰预览完成后立即生成默认裁剪方案】。
- 【已有方案后追加图片】 -> 【保留已有图片方案，仅为新增图片生成预览和默认裁剪方案】。
- 【列表达到 100 张】 -> 【“添加图片”置灰并显示“已达到 100 张上限”】。

#### 7.3.6 错误文案

- 格式不支持：“不支持该图片格式，请添加 JPG、JPEG 或 PNG 图片。”
- 文件过大：“图片超过 60MB，无法添加。”
- 文件损坏：“图片无法读取，请检查文件是否损坏。”
- 图片尺寸过大：“图片尺寸过大，当前设备无法安全处理。”
- 重复文件：“该图片已在当前任务中。”
- 数量超限：“单次最多处理 100 张图片，超出部分未添加。”

### 7.4 自动裁剪方案

#### 7.4.1 目标

- 系统为每张图片生成符合目标比例的默认裁剪区域。
- 系统默认保留摄影师的原始构图，只裁掉目标比例要求下不可避免的边缘区域。

#### 7.4.2 自动构图规则

- 系统在原图范围内计算符合目标宽高比且面积最大的裁剪区域。
- 默认裁剪区域在原图中水平、垂直居中，不依据主体位置重新构图。
- 系统保持目标宽高比，不拉伸图片，不补背景。
- “1440 × 1440”“1440 × 1920”“1440 × 2200”同时定义裁剪宽高比和最终输出像素；结果必须精确匹配所选尺寸。
- 当前规则不检测人物、服装、头部、脚部或其他画面主体。

#### 7.4.3 风险标记规则

- 默认裁剪区域只能保留不足 80% 的原画面时标记“需检查”。
- 默认裁剪区域可以保留至少 80% 的原画面时标记“自动完成”。
- 用户仍可逐张移动或缩放固定比例裁剪框，并可恢复默认居中区域。

#### 7.4.4 交互流程

- 【添加图片】 -> 【按钮显示“正在读取 n/总数”，系统受控并发生成清晰预览和默认裁剪方案】。
- 【当前图片完成计算】 -> 【主区域立即展示裁剪框，不等待整批完成】。
- 【更换裁剪尺寸后点击“生成裁剪方案”】 -> 【仅重新处理“待生成”图片】。

#### 7.4.5 异常反馈

- 默认裁剪异常：“自动裁剪失败，已使用居中区域，请检查。”

### 7.5 单图检查与手动调整

#### 7.5.1 展示规则

- 主区域顶部展示完整文件名和当前状态。
- 主区域居中展示当前图片和裁剪遮罩。
- 裁剪框外区域使用半透明遮罩。
- 裁剪框内展示九宫格辅助线。
- 图片按可用区域等比缩放展示，不使用原始像素尺寸直接撑开页面。
- 主区域底部展示“上一张”“下一张”“恢复自动裁剪”“确认当前”。
- 主区域底部展示“向左旋转 90°”和“向右旋转 90°”两个图标按钮，悬停时显示按钮名称。

#### 7.5.2 手动调整规则

- 用户可以拖动裁剪框改变位置。
- 用户可以拖动裁剪框控制点改变大小。
- 裁剪框宽高比始终锁定为目标比例。
- 裁剪框不得超出原图边界。
- 手动调整完成后立即保存到当前任务状态。
- “恢复自动裁剪”只影响当前图片。

#### 7.5.3 方向校正规则

- 用户每次点击“向左旋转 90°”或“向右旋转 90°”后，当前图片按对应方向旋转 90°。
- 用户可以连续点击完成 180°或恢复到原方向。
- 系统首次生成预览图时先应用原图方向信息，用户旋转以页面中已正确显示的方向为起点。
- 列表缩略图和主区域预览必须同步显示当前方向。
- 系统按照校正后的方向生成清晰预览图和裁剪区域。
- 图片已有裁剪方案或未导出结果时，旋转会清除该图片的旧方案和结果。
- 旋转后的清晰预览生成完成时，系统立即按新方向重新生成该图片的默认裁剪方案，其他图片的状态和结果保持不变。
- 用户在“需检查”筛选中旋转当前图片后，系统切换到“全部”并保持当前图片选中。
- 批量计算、裁剪或导出期间，两个旋转按钮置灰。

#### 7.5.4 检查规则

- “自动完成”图片不需要逐张确认。
- “需检查”图片必须手动调整或点击“确认当前”。
- 手动调整后的“需检查”图片自动视为已确认。
- “确认当前”不生成输出，只表示用户接受当前裁剪区域。

#### 7.5.5 交互流程

- 【拖动或缩放裁剪框】 -> 【实时更新裁剪框并将状态改为“已手动调整”】。
- 【点击“恢复自动裁剪”】 -> 【恢复该图片最近一次自动方案】。
- 【点击“向左旋转 90°”或“向右旋转 90°”】 -> 【更新当前图片方向；已有方案或结果时清除该图片旧数据，清晰预览完成后立即生成新方向的默认裁剪方案】。
- 【点击“确认当前”】 -> 【状态改为“已确认”，自动选中下一张“需检查”图片】。
- 【点击“上一张”或“下一张”】 -> 【保留当前调整并切换图片】。
- 【编辑区非输入、非裁剪拖动且未打开弹窗时按左方向键或右方向键】 -> 【保留当前调整并切换上一张或下一张】。
- 【不存在上一张或下一张】 -> 【对应按钮置灰】。

#### 7.5.6 低分辨率提示

- 当裁剪区域像素小于目标输出尺寸时，主区域展示“原图分辨率不足，导出后可能不够清晰”。
- 低分辨率提示不阻止确认和导出。
- 低分辨率图片在列表中展示“清晰度风险”标记。

### 7.6 确认并导出

#### 7.6.1 提交条件

- 所有图片均已生成可用裁剪区域。
- 不存在“计算中”图片。
- 不存在未确认的“需检查”图片。
- 列表中至少存在一张待导出的图片。

#### 7.6.2 处理规则

- 系统按列表顺序处理图片。
- 系统基于原图和最终裁剪区域生成结果。
- 系统先裁剪，再等比缩放为目标尺寸。
- 输出统一转换为 JPG，质量为 100。
- PNG 的透明区域在 JPG 中使用白色背景。
- 系统必须直接读取原图执行裁剪和缩放，预览图与缩略图不得作为输出来源。
- 系统必须在最终输出时只进行一次 JPG 编码，不得先生成中间 JPG 再重复压缩。
- 输出方向以页面中看到的图片方向为准。
- 输出不保留与画面无关的原图信息。

#### 7.6.3 文件命名

- 输出名称格式为“原文件名_宽x高.jpg”。
- 示例：“IMG_001.jpg”导出为“IMG_001_1440x1920.jpg”。
- 原文件名包含多个点时，只移除最后一个扩展名。
- 文件名包含系统不允许的字符时，系统替换为下划线。
- 目标目录存在同名文件时，依次生成“_2”“_3”序号。
- 示例：“IMG_001_1440x1920_2.jpg”。

#### 7.6.4 交互流程

- 【点击“确认并导出”】 -> 【打开本地目录选择器，不读取原图、不开始处理】。
- 【取消选择目录】 -> 【返回工作台，图片状态和裁剪区域保持不变】。
- 【确认目录】 -> 【按列表顺序读取原图并展示“正在导出 n/总数”】。
- 【单张导出成功】 -> 【该图片状态变为“已导出”，释放该原图的处理资源】。
- 【单张导出失败】 -> 【该图片状态变为“处理失败”，整批继续】。
- 【全部处理结束】 -> 【展示成功数量、失败数量和导出目录】。
- 【点击“重试失败项”】 -> 【重新选择目录，只处理失败图片】。
- 【全部图片已导出】 -> 【主按钮变为“再次导出”】。
- 【点击“再次导出”】 -> 【重新选择目录，并按当前方案再次生成整批文件】。
- 【点击“返回调整”】 -> 【回到检查状态；只有后续被修改图片的导出状态失效】。

#### 7.6.5 处理中退出

- 批量裁剪期间允许点击返回。
- 点击返回后弹出退出确认，不直接离开。
- 用户选择退出时，系统停止尚未开始的处理；已经写入用户目录的文件保留。

#### 7.6.6 失败文案

- 目录不可写：“无法写入所选文件夹，请选择其他文件夹。”
- 空间不足：“磁盘空间不足，部分图片未导出。”
- 文件写入失败：“图片导出失败，请重试。”
- 部分失败：“已导出 n 张，m 张导出失败。”

### 7.7 退出与未导出提醒

#### 7.7.1 触发条件

- 已添加图片但尚未全部导出时，点击顶部返回按钮触发提醒。
- 已添加图片但尚未全部导出时，关闭应用触发提醒。
- 全部图片已成功导出时，返回首页不触发提醒。
- 空任务返回首页不触发提醒。

#### 7.7.2 弹窗规则

- 标题：“退出图片裁剪？”
- 正文：“当前任务还有未导出的图片。退出后，本次裁剪区域和处理结果将被清除，无法恢复。”
- 次按钮：“继续处理”。
- 主按钮：“退出并放弃”。
- 点击遮罩层不关闭弹窗。
- 按下 Esc 等同于“继续处理”。

#### 7.7.3 交互流程

- 【点击“继续处理”】 -> 【关闭弹窗并保留当前任务】。
- 【点击“退出并放弃”】 -> 【清除当前任务并返回首页】。
- 【任务全部导出后点击返回】 -> 【直接返回首页并清除当前任务】。

### 7.8 中英文与主题

#### 7.8.1 语言规则

- 所有按钮、状态、空态、弹窗和错误信息均提供中文和英文文案。
- 切换语言后，当前任务、选中图片和裁剪区域保持不变。
- 文件名保持原始语言，不翻译、不改写。

#### 7.8.2 主题规则

- 工作台跟随 Lumina 当前明暗主题。
- 切换主题后，当前任务和裁剪区域保持不变。
- 裁剪框边界、控制点和遮罩在两种主题下均需清晰可见。

## 8. 非功能需求说明

### 8.1 性能

#### 8.1.1 大图批量处理

- 100 张有效图片加入后，用户可以继续滚动列表和切换当前图片。
- 批量计算、裁剪和导出均需要展示总数、完成数和当前状态。
- 缩略图列表只加载当前可见区域及相邻缓冲区域的缩略图。
- 主区域只加载当前图片的清晰预览图，不加载原图作为编辑图。
- 清晰预览图的最长边为 2560px，并保持原图可见方向和宽高比例。
- 自动构图、区域展示和手动调整均基于清晰预览图完成。
- 裁剪区域使用相对位置和比例表达，不依赖预览图的固定像素尺寸。
- 生成预览图时逐张读取原文件；单张完成后立即释放原图解码数据。
- 最终裁剪时按队列重新读取原图；同时处理的原图不得超过 2 张。
- 最终结果直接由原图和已确认裁剪区域生成，不经过预览图二次放大。
- 处理数量必须根据实际像素和可用内存限流，不得只依据文件体积决定并发。

#### 8.1.2 低配置设备基线

- 验收设备为 8GB 内存、4 核 CPU、无独立显卡的设备。
- 自动构图、手动调整、裁剪和导出不得要求独立显卡或专用图形计算能力。
- 设备资源不足时，系统降低并发数量，不降低输出尺寸和 JPG 质量。
- 系统无法安全处理单张图片时，跳过该图片并显示“图片尺寸过大，当前设备无法安全处理”。

### 8.2 稳定性

#### 8.2.1 部分失败

- 单张失败不结束整批任务。
- 成功结果不因其他图片失败而失效。
- 重试失败项不重复处理成功项。
- 重复点击提交按钮不得创建重复任务。

### 8.3 隐私

#### 8.3.1 本地边界

- 本功能不得因图片分析、裁剪、缩放或导出访问网络。
- 页面不得要求用户登录后才能使用本功能。
- 原图只用于当前本地任务。
- 退出任务后，系统清除本次任务的临时预览和未导出结果。

### 8.4 输出质量

#### 8.4.1 图片结果

- 输出像素必须与目标尺寸完全一致。
- 输出不得出现宽高比例拉伸。
- 输出不得出现由图片方向信息导致的横竖颠倒。
- JPG 输出质量固定为 100。
- 输出必须直接基于原图生成，不得使用预览图或缩略图生成。
- 每张图片从原图到最终 JPG 只允许进行一次有损编码。
- 缩小图片时必须使用高质量缩放；裁剪区域小于目标尺寸时不得静默放大，必须展示清晰度风险。

## 9. 验收标准

### 9.1 入口与尺寸

- [ ] 首页“新建项目”左侧展示“图片裁剪”入口。
- [ ] 点击入口进入独立工作台，不创建项目记录。
- [ ] 未选择尺寸时不能添加图片。
- [ ] 页面只提供三个确认过的目标尺寸。

### 9.2 导入与列表

- [ ] 支持一次添加多张 JPG、JPEG、PNG 图片。
- [ ] 支持同一任务累计添加 100 张图片。
- [ ] 支持单张 60MB 图片正常进入任务。
- [ ] 超过 1.2 亿像素的图片不会进入任务，并显示设备安全提示。
- [ ] 超过数量、大小或格式限制时给出明确原因。
- [ ] 重复图片不会重复进入列表。
- [ ] 追加图片不会清空已有裁剪方案。
- [ ] 每张图片完成清晰预览后立即获得默认裁剪方案，无需再点击“生成裁剪方案”。
- [ ] 导入阶段同时读取原图的数量不超过 2 张。

### 9.3 自动裁剪

- [ ] 默认裁剪框是目标比例下能够保留原画面面积最大的居中矩形。
- [ ] 默认裁剪区域保留不足 80% 原画面时，图片标记“需检查”。
- [ ] 默认裁剪区域保留至少 80% 原画面时，图片标记“自动完成”。
- [ ] 导入并自动生成默认裁剪方案期间可以看到逐张状态和总体进度。
- [ ] 单张计算失败不影响其他图片。
- [ ] 所有裁剪方案均符合目标宽高比并位于原图范围内。

### 9.4 手动复核

- [ ] 用户可以移动和缩放裁剪框。
- [ ] 用户无法把裁剪框移出原图边界。
- [ ] 用户调整时裁剪框比例保持不变。
- [ ] 用户可以恢复当前图片的自动裁剪区域。
- [ ] 用户可以把当前图片向左或向右旋转 90°，并连续操作完成 180°校正。
- [ ] 列表缩略图和主区域预览同步显示旋转后的方向。
- [ ] 图片旋转后，预览、裁剪区域和最终导出方向保持一致。
- [ ] 已有方案的图片旋转后仅该图片重新生成新方向的默认裁剪方案，其他图片保持原状态。
- [ ] 在“需检查”筛选中旋转当前图片后，页面切换到“全部”且当前图片保持选中。
- [ ] 批量计算、裁剪和导出期间不能旋转图片。
- [ ] 存在未确认“需检查”图片时不能开始批量裁剪。
- [ ] 确认当前风险图片后自动定位下一张风险图片。
- [ ] 右侧编辑区可通过左右方向键切换上一张和下一张，输入控件、裁剪拖动和弹窗状态下不会误切换。

### 9.5 裁剪与导出

- [ ] 三种尺寸的输出宽高像素均完全正确。
- [ ] 输出统一为质量 100 的 JPG。
- [ ] 透明 PNG 导出为 JPG 后，透明区域显示为白色。
- [ ] 点击“确认并导出”后立即出现本地目录选择器。
- [ ] 取消目录选择不会开始处理，也不会改变图片状态和裁剪区域。
- [ ] 确认目录后才开始逐张读取原图、裁剪、缩放和写入。
- [ ] 输出直接基于原图生成，未使用预览图或缩略图。
- [ ] 从原图到最终 JPG 只发生一次有损编码。
- [ ] 输出图片不存在非等比拉伸。
- [ ] 文件名符合“原文件名_宽x高.jpg”规则。
- [ ] 同名文件自动增加序号且不覆盖已有文件。
- [ ] 100 张图片可以选择一个本地文件夹批量导出。
- [ ] 部分失败时成功文件保留，失败项可以单独重试。
- [ ] 全部导出成功时，“确认”和关闭完成弹窗保留当前结果；点击“添加新批次”才清空图片和预览缓存，并保留当前裁剪尺寸。

### 9.6 性能、隐私与退出

- [ ] 100 张、单张不超过 60MB 的任务处理中页面仍可滚动和切换图片。
- [ ] 列表滚动时只加载可见区域及相邻区域的缩略图。
- [ ] 工作台只加载当前图片的清晰预览图，不把原图作为编辑图。
- [ ] 裁剪框在预览图上调整后，可以准确映射到原图并生成相同构图的结果。
- [ ] 生成预览图和最终结果时，同时处理的原图不超过 2 张。
- [ ] 单张处理完成后，对应原图解码数据被释放，不随任务数量持续累积。
- [ ] 8GB 内存、4 核 CPU、无独立显卡的设备可以完成 100 张测试任务。
- [ ] 设备资源不足时降低处理并发，不降低输出尺寸或 JPG 质量。
- [ ] 断网状态下可以完成导入、自动裁剪、手动调整、裁剪和导出。
- [ ] 任务过程未产生图片或裁剪数据的网络请求。
- [ ] 有未导出图片时返回首页和关闭应用均出现退出提醒。
- [ ] 全部导出后返回首页不出现未导出提醒。
- [ ] 退出并放弃后重新进入工作台，不恢复上次任务。

### 11.4 最终口径

#### 11.4.1 数据归属

- 原图事实以用户选择的本地文件为准。
- 裁剪事实以当前任务中最近一次合法裁剪区域为准。
- 输出事实以用户最后一次确认目录时的裁剪区域和方向为准。
- 导出成功以文件实际写入用户选择目录为准。
- 项目列表和画布项目不拥有本功能数据。

#### 11.4.2 进入技术设计前结论

- 本文无阻塞性开放问题。
- 技术设计需要覆盖默认裁剪几何、预览图生成、裁剪区域映射、固定资源预算、100 张大图队列、任务状态管理、导出失败重试和关闭应用拦截。
- 技术设计必须保证界面层只接收缩略图和清晰预览图，原图仅在生成预览和最终结果时按队列读取。
- 技术设计不得改变本文确认的全程本地处理边界。
