# 批量图片固定画布与空白补全产品需求文档

## 1. 项目背景

### 1.1 需求简介

#### 1.1.1 核心需求

- 用户需要把不同比例的模特图输出为统一电商尺寸。
- 现有“裁剪填满”会在原图与输出比例差异较大时裁掉人物。
- 系统需要增加“固定画布”，让用户先缩放、移动整张图片，再处理画布空白。
- 系统需要支持区域拉伸和 AI 补全两种空白处理方式。
- 每张图片需要独立选择“裁剪填满”或“固定画布”。

### 1.2 业务诉求

#### 1.2.1 当前问题

- 竖版全身图输出为方图时，用户无法同时保留头部和脚部。
- 用户需要在 Photoshop 中新建目标尺寸画布，再缩小和移动原图。
- 简单背景需要通过矩形选区拉伸，复杂背景需要通过 AI 延续场景。
- 批次内每张图片的构图不同，不能用一个批次构图方式覆盖所有图片。

#### 1.2.2 预期结果

- 用户可以继续使用现有“裁剪填满”。
- 用户可以使用固定白色画布完整保留人物。
- 用户可以在确认构图后框选画面区域并向空白方向拉伸。
- 用户可以把调整后的完整画布交给 AI，自动补齐剩余空白。
- 用户可以在同一批次中混合导出两种构图方式的结果。

### 1.3 目标用户

#### 1.3.1 主要用户

- 需要制作电商方图、竖图的设计人员。
- 需要批量处理服装模特图的摄影后期人员。
- 需要检查人物完整性和背景连续性的运营人员。

### 1.4 默认假设

#### 1.4.1 本期假设

- DA-1：每个批次只选择一个输出尺寸。
- DA-2：输出尺寸沿用“1440 × 1440”“1440 × 1920”“1440 × 2200”。
- DA-3：每批最多添加 100 张图片。
- DA-4：支持 JPG、JPEG、PNG。
- DA-5：输出尺寸为 1440 × 1440 时，新添加图片和切换尺寸后重置的全部图片默认使用“固定画布”；其他输出尺寸默认使用“裁剪填满”。
- DA-6：构图方式属于单张图片，不提供用户可配置的“整批默认”和“跟随批次”。
- DA-7：固定画布的底色固定为白色，不提供颜色设置。
- DA-8：固定画布只允许整图等比缩放和移动，不允许整图非等比变形。
- DA-9：固定画布不抠取人物，不单独缩放人物。
- DA-10：区域拉伸只在用户确认固定画布构图后使用。
- DA-11：区域拉伸由用户在当前图片中粗略绘制选区；系统按拖动长宽自动锁定为贯穿画布的横向条带或纵向条带。
- DA-12：区域拉伸允许同一张图片创建多个拉伸区域。
- DA-13：每个拉伸区域只向相邻空白方向拉伸。
- DA-14：区域拉伸不改变原始图片文件。
- DA-15：AI 补全读取缩放、移动后的完整固定画布。
- DA-16：AI 补全把画布空白作为生成范围，把已有画面作为保护内容和场景参考。
- DA-17：画布空白按构图记录判断，不按像素是否为白色判断。
- DA-18：区域拉伸和 AI 补全可以在同一张图片中连续使用。
- DA-19：AI 补全不会自动发起，必须由用户主动确认。
- DA-20：AI 补全可能产生服务商费用，提交前必须展示确认弹窗。
- DA-21：AI 模型来自设置页中已配置并启用的图片编辑模型。
- DA-22：每次 AI 补全生成一个候选结果。
- DA-23：本期任务不跨应用重启恢复。
- DA-24：本地裁剪、构图、区域拉伸和导出不上传图片。
- DA-25：AI 补全只上传当前完整画布、空白范围和用户填写的提示词。
- DA-26：输出统一为 JPG，质量为 100，不覆盖原图和已有同名文件。
- DA-27：固定画布保留白色区域也属于有效结果，不强制使用填充工具。
- DA-28：用户确认构图后，当前结果立即可导出；拉伸和 AI 成功结果均即时生效，不提供二次完成或接受按钮。
- DA-29：系统跨图片、批次和应用重启记住最近一次成功提交的 AI 模型与生成清晰度，不记住提示词。
- DA-30：取消 AI 只立即停止本地等待和结果接收；服务商任务可能继续执行并产生费用。
- DA-31：AI 任务在图片间切换后继续在后台运行，同一批次允许多张图片同时处于生成中。
- DA-32：“处理下一张”严格选择当前图片在完整列表中的下一张，不跳过任何生成中、已生成、失败、已导出或其他状态。
- DA-33：主编辑区使用左右方向键切换上一张和下一张；图片列表行获得焦点时使用上下方向键切换相邻可见行。
- DA-34：区域拉伸模式在完成一次拉伸后保持激活，直到用户主动关闭或切换工作阶段。

## 2. 范围

### 2.1 本期包含

#### 2.1.1 功能范围

- 保留批量添加图片、固定输出尺寸和批量导出。
- 保留现有“裁剪填满”的自动裁剪和手动调整。
- 新增单图“固定画布”构图方式。
- 支持在固定画布中等比缩放和移动整张图片。
- 支持确认构图、返回调整和恢复初始构图。
- 支持矩形选区、方向拉伸、多个拉伸区域、撤销和删除。
- 支持使用完整固定画布进行 AI 补全。
- 支持 AI 模型选择、清晰度记忆、可编辑提示词、费用确认、处理中取消、成功自动生效和失败重试。
- 支持 AI 任务后台并行、处理下一张和列表生成状态反馈。
- 支持单张图片在两种构图方式之间切换。
- 支持同一批次混合导出两种构图结果。
- 支持中英文界面和明暗主题。

### 2.2 本期不包含

#### 2.2.1 排除范围

- 不提供“设置范围”“整批默认”和“恢复批次设置”，构图方式切换器前不显示“当前图片”标签。
- 不提供自动边缘取样、取样宽度和取样方向设置。
- 不提供内容识别缩放和自动保护人物的非等比缩放。
- 不提供自定义画布颜色和透明画布。
- 不提供自定义输出宽度和高度。
- 不提供一批图片同时导出多个尺寸。
- 不提供人物抠图、服装抠图和主体单独缩放。
- 不提供套索、魔棒、画笔遮罩和自由形状选区。
- 不提供旋转、透视、扭曲和变形拉伸。
- 不提供批量发起 AI 补全。
- 不提供一次生成多个 AI 结果并列对比。
- 不提供任务历史、重启恢复和云端任务同步。
- 不提供把适配结果自动写入 Lumina 画布项目。

### 2.3 后续候选

#### 2.3.1 延后评估

- 自定义输出尺寸和常用尺寸收藏。
- 自动推荐可拉伸的背景区域。
- 内容识别缩放。
- 画笔补全范围和局部重做。
- 多个 AI 候选结果对比。
- 同组图片复制缩放和位置参数。
- 任务保存、历史记录和继续处理。
- 把适配结果发送到 Lumina 画布。

## 3. 用户场景

### 3.1 正常路径

#### 3.1.1 使用裁剪填满

- GIVEN 用户已选择输出尺寸并添加图片，WHEN 图片预览完成，THEN 系统按现有规则生成裁剪填满方案。
- GIVEN 当前图片使用“裁剪填满”，WHEN 用户调整裁剪框，THEN 系统实时更新该图片的裁剪结果。
- GIVEN 用户确认裁剪结果，WHEN 用户切换到下一张图片，THEN 当前图片保持可导出状态。

#### 3.1.2 使用固定画布

- GIVEN 当前图片使用“裁剪填满”，WHEN 用户切换到“固定画布”，THEN 系统显示目标尺寸对应的白色画布，并完整放入原图。
- GIVEN 用户位于固定画布构图阶段，WHEN 用户拖动图片，THEN 系统只改变当前图片在画布中的位置。
- GIVEN 用户位于固定画布构图阶段，WHEN 用户调整缩放，THEN 系统等比缩放整张图片。
- GIVEN 人物位置和大小合适，WHEN 用户点击“确认构图”，THEN 系统锁定当前构图并进入空白处理阶段。

#### 3.1.3 使用区域拉伸

- GIVEN 用户已确认固定画布构图，WHEN 用户点击“区域拉伸”，THEN 画布进入矩形选区状态。
- GIVEN 画布处于矩形选区状态，WHEN 用户在已有画面中拖出矩形，THEN 系统展示选区和可用方向手柄。
- GIVEN 选区左侧存在空白，WHEN 用户向左拖动方向手柄，THEN 系统把选中画面向左拉伸并实时预览。
- GIVEN 当前图片仍有其他方向空白，WHEN 用户再次创建选区，THEN 系统保留已有拉伸并新增拉伸操作。
- GIVEN 用户已确认构图，WHEN 用户完成一次有效拉伸，THEN 拉伸立即生效且当前结果保持可导出状态。

#### 3.1.4 使用 AI 补全

- GIVEN 用户已确认固定画布构图且画布存在空白，WHEN 用户点击“AI 补全”，THEN 系统展示当前完整画布、模型和费用确认弹窗。
- GIVEN 用户确认提交，WHEN AI 任务开始，THEN 系统锁定当前图片编辑并展示处理状态。
- GIVEN 当前图片正在 AI 补全，WHEN 用户点击“处理下一张”，THEN 系统选择列表中严格相邻的下一张，同时当前任务继续在后台运行。
- GIVEN 多张图片均已提交 AI 补全，WHEN 用户在图片间切换，THEN 各任务独立查询并分别更新结果。
- GIVEN AI 返回有效结果，WHEN 系统保存结果，THEN 完整补全画布自动成为当前结果并进入可导出状态。
- GIVEN 用户在提交或生成过程中取消，WHEN 本地收到迟到的任务或结果，THEN 系统忽略迟到内容并保持取消前画布可导出。

#### 3.1.5 混合使用

- GIVEN 用户已完成一个区域拉伸，WHEN 画布仍存在空白且用户点击“AI 补全”，THEN 系统把当前完整画布作为 AI 输入并只补齐剩余空白。
- GIVEN 批次包含两种构图方式，WHEN 用户点击“批量导出”，THEN 系统按每张图片当前选择的构图结果分别导出。

#### 3.1.6 单图切换构图方式

- GIVEN 当前图片使用“裁剪填满”，WHEN 用户切换到“固定画布”，THEN 其他图片的构图方式保持不变。
- GIVEN 当前图片在两种方式下都有调整草稿，WHEN 用户来回切换，THEN 系统分别恢复两种方式最近一次的草稿。
- GIVEN 当前图片正在 AI 补全或导出，WHEN 用户查看构图方式，THEN 两个构图方式按钮均不可点击。

### 3.2 异常与边界

#### 3.2.1 区域拉伸异常

- GIVEN 用户的矩形选区全部位于空白区域，WHEN 用户结束框选，THEN 系统取消选区并提示“请在图片内容中选择需要拉伸的区域”。
- GIVEN 选区对应方向没有空白，WHEN 用户尝试向该方向拉伸，THEN 对应方向手柄不显示。
- GIVEN 用户把拉伸范围拖出画布，WHEN 指针越过画布边界，THEN 系统把拉伸终点限制在画布边界。
- GIVEN 拉伸来源包含人物或商品，WHEN 用户完成拉伸，THEN 系统不自动阻断，用户自行检查结果。

#### 3.2.2 AI 补全异常

- GIVEN 画布没有空白，WHEN 用户查看“AI 补全”，THEN 按钮置灰并提示“当前画布没有需要补全的区域”。
- GIVEN 用户没有可用图片编辑模型，WHEN 用户点击“AI 补全”，THEN 系统提示“请先在设置中配置可用的图片编辑模型”。
- GIVEN 用户取消费用确认，WHEN 弹窗关闭，THEN 当前构图和拉伸结果保持不变。
- GIVEN AI 正在提交或生成，WHEN 用户点击取消，THEN 界面立即恢复提交前画布并提示服务商任务可能继续计费。
- GIVEN AI 提交失败，WHEN 系统收到错误，THEN 系统提示可读原因并保留提交前画布。
- GIVEN AI 处理中断网，WHEN 任务查询无法继续，THEN 系统展示“重新查询”；用户也可以取消 AI 补全，立即恢复提交前画布并忽略迟到结果，同时提示服务商任务可能继续执行并产生费用。
- GIVEN AI 返回结果失败，WHEN 用户点击“重试”，THEN 系统使用当前完整画布重新发起一次任务。

#### 3.2.3 模式与尺寸边界

- GIVEN 当前图片已有 AI 结果，WHEN 用户返回构图并改变图片位置或缩放，THEN 系统移除已生效的 AI 结果，并保留修改前草稿用于撤销。
- GIVEN 当前图片已有拉伸结果，WHEN 用户返回构图并改变图片位置或缩放，THEN 系统清除与旧构图不再匹配的拉伸结果。
- GIVEN 批次已有图片，WHEN 用户切换输出尺寸，THEN 系统二次确认并说明所有图片调整和 AI 结果将重置。
- GIVEN 用户取消切换输出尺寸，WHEN 弹窗关闭，THEN 当前批次保持不变。

### 3.3 状态变化

#### 3.3.1 单图状态

- GIVEN 图片导入完成，WHEN 初始裁剪方案生成，THEN 状态变为“待确认”。
- GIVEN 用户切换到固定画布，WHEN 开始移动或缩放，THEN 状态变为“调整构图”。
- GIVEN 用户确认固定画布构图，WHEN 画布存在空白，THEN 状态变为“可导出”，同时开放空白处理工具。
- GIVEN 用户正在绘制或拉伸选区，WHEN 操作未完成，THEN 状态变为“区域拉伸”。
- GIVEN AI 任务已提交，WHEN 等待结果，THEN 状态变为“AI 生成中”。
- GIVEN AI 结果已返回，WHEN 结果保存成功，THEN 状态变为“AI 已生成”并可导出。
- GIVEN AI 生成失败，WHEN 系统保留提交前画布，THEN 状态变为“AI 生成失败”并仍允许导出提交前结果。
- GIVEN 用户确认固定画布构图，WHEN 进入空白处理阶段，THEN 状态变为“可导出”。
- GIVEN 文件写入成功，WHEN 导出完成，THEN 状态变为“已导出”。

## 4. 需求清单

### 4.1 功能需求

#### 4.1.1 需求编号

- FR-1：系统必须允许用户为批次选择一个输出尺寸。
- FR-2：系统必须允许用户添加、删除和切换批次中的图片。
- FR-3：系统必须把构图方式保存为单张图片属性。
- FR-4：系统必须允许单张图片在“裁剪填满”和“固定画布”之间切换。
- FR-5：系统必须保证切换单张图片构图方式时不改变其他图片。
- FR-6：系统必须保留现有“裁剪填满”的裁剪能力。
- FR-7：系统必须按输出尺寸展示固定白色画布。
- FR-8：系统必须允许用户在固定画布中等比缩放整张图片。
- FR-9：系统必须允许用户在固定画布中移动整张图片。
- FR-10：系统必须提供“恢复初始构图”。
- FR-11：系统必须提供“确认构图”和“返回调整”。
- FR-12：系统必须在确认构图后提供“区域拉伸”。
- FR-13：系统必须把粗略选区自动锁定为贯穿画布的横向或纵向条带，并允许用户移动、调整和取消选区。
- FR-14：系统必须只展示存在相邻空白的拉伸方向。
- FR-15：系统必须允许用户拖动方向手柄预览拉伸结果。
- FR-16：系统必须允许同一张图片创建多个拉伸区域。
- FR-17：系统必须允许撤销、重做和删除拉伸操作。
- FR-18：系统必须在固定画布存在空白时提供“AI 补全”。
- FR-19：系统必须把当前完整画布作为 AI 补全上下文。
- FR-20：系统必须把剩余空白作为 AI 生成范围。
- FR-21：系统必须在 AI 提交前展示模型、生成清晰度和费用说明。
- FR-22：系统必须展示名称为“提示词”的必填输入框，默认预填本地化的空白区域补全提示词，并允许用户修改。
- FR-23：系统必须展示 AI 提交、处理、成功、失败和中断状态，并允许用户在提交和处理中取消。
- FR-24：系统必须让 AI 成功结果自动生效，并保证取消后的迟到结果不能覆盖当前画布。
- FR-25：系统必须允许区域拉伸后继续使用 AI 补全。
- FR-26：系统必须为每张图片分别保存两种构图方式的当前草稿。
- FR-27：系统必须在更改输出尺寸前提示调整结果将重置。
- FR-28：系统必须允许同一批次混合导出不同构图方式的结果。
- FR-29：系统必须跳过没有可导出结果的图片，并在导出前展示数量。
- FR-30：系统必须在导出完成后展示成功数量、失败数量和输出目录。
- FR-31：系统必须支持中英文文案和明暗主题。
- FR-32：系统必须持久记住最近一次成功提交的 AI 模型和生成清晰度，每次打开弹窗时把提示词重置为本地化默认值。
- FR-33：系统必须允许不同图片的 AI 补全任务在后台并行运行，离开当前图片不得取消其任务。
- FR-34：系统必须在 AI 处理覆盖层提供“处理下一张”，严格选择完整图片列表的下一项且最后一张不可点击。
- FR-35：系统必须在图片列表中显式展示“AI 生成中”“AI 已生成”“AI 生成失败”，不得只依赖圆点或悬停提示。
- FR-36：系统必须在固定画布构图、填充、AI 生成中和生成完成状态展示“上一张、当前序号/总数、下一张”，并支持编辑区左右键和列表行上下键导航。
- FR-37：系统必须让 1440 × 1440 图片默认进入固定画布，同时保留有效裁剪草稿，允许单张切回裁剪填满。

### 4.2 非功能需求

#### 4.2.1 需求编号

- NFR-1：系统必须在拖动图片、缩放图片和拉伸选区时保持连续预览。
- NFR-2：系统必须避免在每一帧操作中写入重持久化数据。
- NFR-3：系统必须使用预览图完成编辑，使用原图生成本地导出结果。
- NFR-4：系统必须保证本地处理过程不上传图片。
- NFR-5：系统必须在 AI 提交前明确说明图片会发送给所选模型服务商。
- NFR-6：系统必须支持 1280 × 720 及以上桌面窗口使用主要功能。
- NFR-7：系统必须保证键盘焦点、按钮置灰和提示信息可识别。
- NFR-8：系统必须保证导出结果的像素尺寸与所选输出尺寸完全一致。

## 5. 关键决策

### 5.1 决策记录

| 决策 | 选择 | 理由 | 否决方案 |
|---|---|---|---|
| 构图方式归属 | 单张图片独立设置 | 批次内图片构图不同 | 整批默认、单图覆盖 |
| 第二种构图方式名称 | 固定画布 | 直接描述画布不随图片变化 | 保全画面、智能扩图 |
| 固定画布底色 | 白色 | 符合电商图和用户当前流程 | 自定义颜色、透明底 |
| 固定画布调整能力 | 整图等比缩放和移动 | 保持人物比例 | 非等比缩放、主体抠图 |
| 空白处理时机 | 确认构图后处理 | 分离构图和补空白两种任务 | 构图时自动填充 |
| 本地填充方式 | 用户矩形选区后定向拉伸 | 与用户 Photoshop 流程一致 | 自动边缘取样、取样宽度 |
| 拉伸结果 | 非破坏性操作 | 支持撤销和多个区域 | 直接改写原图像素 |
| AI 输入 | 当前完整固定画布 | AI 需要人物、背景和位置关系 | 只上传白色区域 |
| AI 生成范围 | 当前剩余空白 | 避免无必要重绘人物 | 整张画布全部重绘 |
| 区域拉伸与 AI | 允许组合使用 | 用户可先完成简单背景再补复杂区域 | 两者只能二选一 |
| 模式切换 | 分别保留两种草稿 | 便于单图比较和返回 | 切换即清空上一方式 |
| 1440 × 1440 默认构图 | 固定画布 | 方图优先保留全身人物 | 默认裁剪填满 |
| AI 多图处理 | 后台并行、严格下一张 | 减少等待且保持批次顺序可预测 | 离开即取消、自动跳过状态 |
| 智能内容识别缩放 | 本期不做 | 结果不稳定，可能影响人体和服装比例 | 作为第三种构图方式 |

## 6. 公共规则

### 6.1 日期与时间规则

#### 6.1.1 适用范围

- 本功能不展示业务日期和时间。
- AI 处理中只展示状态，不展示无法保证准确的剩余时间。

### 6.2 数值与单位规则

#### 6.2.1 展示规则

- 图片尺寸使用“宽 × 高”像素格式。
- 缩放比例使用整数百分比。
- 固定画布初始完整显示定义为 100%。
- 固定画布缩放范围为 20% 至 200%。
- 文件大小小于 1MB 时保留整数 KB，大于等于 1MB 时保留一位 MB。
- 图片序号使用“当前序号/总数”。

### 6.3 数据刷新规则

#### 6.3.1 写入后的刷新目标

- 【切换单图构图方式】 -> 【刷新当前编辑区、当前列表状态】。
- 【调整裁剪、缩放或位置】 -> 【刷新当前预览、当前图片状态】。
- 【确认构图】 -> 【刷新当前工具栏、当前图片状态、空白范围】。
- 【完成区域拉伸】 -> 【刷新当前预览、空白范围、撤销记录】。
- 【AI 返回成功】 -> 【自动刷新当前预览、当前图片状态、批量导出数量】。
- 【导出完成】 -> 【刷新列表状态、成功数量、失败数量】。

### 6.4 可操作范围规则

#### 6.4.1 通用规则

- 未选择输出尺寸时，“添加图片”不可点击。
- 没有图片时，编辑区只展示空状态。
- AI 补全中和导出中，当前图片的构图、拉伸和模式切换不可操作。
- AI 提交和处理中允许取消，其他构图与模式切换操作保持不可用。
- 当前图片没有空白时，“AI 补全”不可点击。
- 当前图片未确认固定画布构图时，“区域拉伸”和“AI 补全”不可点击。

### 6.5 数据归属与冲突规则

#### 6.5.1 单图归属

- 输出尺寸归属当前批次。
- 构图方式归属当前图片。
- 裁剪草稿归属当前图片的“裁剪填满”。
- 图片位置、缩放、拉伸记录和 AI 结果归属当前图片的“固定画布”。
- 同一图片的两种构图草稿互不覆盖。
- 最终导出以该图片当前选中的构图方式为准。

#### 6.5.2 覆盖与重置

- AI 成功结果会直接替换当前固定画布结果，不覆盖原图文件。
- 取消 AI 会恢复提交前画布；迟到任务 ID 和结果一律忽略。
- 返回构图并改变缩放或位置，会清除基于旧构图产生的拉伸和 AI 结果。
- 更改批次输出尺寸，会重置所有图片的两种构图草稿和 AI 结果。

### 6.6 空白范围规则

#### 6.6.1 判断口径

- 固定画布中未被原图或已完成拉伸覆盖的区域属于空白。
- 原图中的白色背景不属于空白。
- 已完成区域拉伸覆盖的区域不再属于空白。
- AI 补全成功后，当前画布不再存在待补全空白。

## 7. 详细功能说明

### 7.1 输出尺寸与图片列表

#### 7.1.1 位置与目标

- 位置：图片适配 - 工作台左栏 - 输出尺寸。
- 目标：设置批次统一输出尺寸并管理图片。

#### 7.1.2 展示规则

- 输出尺寸使用三个分段按钮展示。
- 图片列表按添加顺序展示。
- 每行展示缩略图、文件名、文件大小、构图方式和状态。
- 构图方式显示“裁剪填满”或“固定画布”。
- AI 任务状态使用可见文字展示“AI 生成中”“AI 已生成”“AI 生成失败”。

#### 7.1.3 交互流程

- 【选择输出尺寸】 -> 【“添加图片”变为可点击】。
- 【添加有效图片】 -> 【列表追加图片并选中第一张新图片】。
- 【点击图片行】 -> 【编辑区切换到该图片最近状态】。
- 【图片行获得焦点后按上/下方向键】 -> 【严格选择上一条/下一条可见图片行，并把焦点滚动到可见范围】。
- 【删除图片】 -> 【仅移除当前批次中的该图片，不删除原文件】。
- 【更改已有批次输出尺寸】 -> 【展示重置确认弹窗】。

#### 7.1.4 异常与边界

- 无有效图片时显示“选择输出尺寸后添加图片”。
- 超过 100 张时只接受前 100 张，并提示剩余数量。
- 单张文件失败时保留其他成功图片，并在列表展示失败原因。

### 7.2 单图构图方式切换

#### 7.2.1 位置与目标

- 位置：图片适配 - 当前图片顶部 - 构图方式。
- 目标：让当前图片独立选择构图方式。

#### 7.2.2 展示规则

- 使用“裁剪填满”“固定画布”两个分段按钮。
- 当前选中方式高亮。
- 切换后只更新当前图片。

#### 7.2.3 交互流程

- 【首次切换到固定画布】 -> 【白色画布显示，原图按完整显示居中】。
- 【切换到已有草稿的方式】 -> 【恢复该方式最近一次草稿】。
- 【AI 补全中或导出中】 -> 【两个按钮置灰】。

### 7.3 裁剪填满

#### 7.3.1 位置与目标

- 位置：图片适配 - 当前图片 - 裁剪填满。
- 目标：延续现有裁剪操作。

#### 7.3.2 交互流程

- 【进入裁剪填满】 -> 【展示固定比例裁剪框】。
- 【拖动或缩放裁剪框】 -> 【实时更新裁剪预览】。
- 【点击“恢复自动”】 -> 【恢复系统初始裁剪方案】。
- 【点击“确认当前”】 -> 【当前图片进入可导出状态】。

### 7.4 固定画布构图

#### 7.4.1 位置与目标

- 位置：图片适配 - 当前图片 - 固定画布 - 调整构图。
- 目标：在不改变画布尺寸的前提下调整整张图片。

#### 7.4.2 展示规则

- 画布按输出比例展示，底色为白色。
- 原图边界使用细线显示，便于区分图片和画布。
- 画布外区域使用工作台背景色。
- 工具栏展示缩放滑杆、缩小、放大、完整显示、恢复初始构图和“确认构图”。

#### 7.4.3 交互流程

- 【拖动画布中的图片】 -> 【图片跟随指针移动】。
- 【调整缩放滑杆】 -> 【图片围绕当前中心等比缩放】。
- 【点击“完整显示”】 -> 【原图完整居中显示，缩放值恢复 100%】。
- 【点击“恢复初始构图”】 -> 【清除当前固定画布调整并恢复首次状态】。
- 【点击“确认构图”】 -> 【锁定图片变换、进入空白处理阶段并立即标记为可导出】。

#### 7.4.4 异常与边界

- 图片允许部分移出画布，但至少保留 10% 面积可见。
- 缩放达到上限或下限后，对应缩放操作不可继续。
- 返回调整后第一次改变构图时，系统清除旧拉伸和 AI 结果并提供一次撤销。

### 7.5 固定画布空白处理入口

#### 7.5.1 位置与目标

- 位置：图片适配 - 当前图片 - 固定画布 - 填充空白。
- 目标：在构图确认后选择区域拉伸或 AI 补全。

#### 7.5.2 展示规则

- 工具栏使用 32 × 32 图标按钮展示“区域拉伸”“AI 补全”，命令按钮保留“返回调整”。
- 已存在拉伸操作时展示撤销、重做和删除操作，不展示拉伸区域数量。
- 构图和空白处理阶段均展示上一张、当前序号/总数和下一张；编辑区非输入态支持左右方向键切换。
- 画布没有空白时隐藏区域提示，并将“AI 补全”置灰。

#### 7.5.3 交互流程

- 【点击“返回调整”】 -> 【退出空白处理并解锁图片变换】。
- 【点击“确认构图”】 -> 【当前固定画布立即进入可导出状态】。
- 【保留白色空白】 -> 【允许直接导出，不弹出阻断提示】。

### 7.6 区域拉伸

#### 7.6.1 位置与目标

- 位置：图片适配 - 当前图片 - 固定画布 - 区域拉伸。
- 目标：使用已有背景像素填充相邻空白。

#### 7.6.2 展示规则

- 激活后指针显示为十字选择状态。
- 用户完成一次有意义的拖动后，系统按粗略矩形的长宽锁定条带方向并展示虚线选区。
- 粗略窄高选区锁定为贯穿画布高度的纵向条带，只提供左右拉伸方向；粗略宽矮选区锁定为贯穿画布宽度的横向条带，只提供上下拉伸方向。
- 拉伸预览覆盖在原图和空白之上。
- 已完成拉伸区域在取消选中后不显示边框。

#### 7.6.3 交互流程

- 【在已有画面内拖动】 -> 【按首次有效拖动方向创建全轴条带选区并锁定方向】。
- 【拖动选区内部】 -> 【移动选区，不改变像素】。
- 【拖动选区边角】 -> 【调整来源范围】。
- 【拖动方向手柄】 -> 【选中像素向该方向非等比拉伸】。
- 【松开方向手柄】 -> 【生成一个拉伸操作并记录撤销点】。
- 【完成一次有效拉伸】 -> 【清除当前选区并保持区域拉伸模式，可直接继续框选下一处】。
- 【按 Esc】 -> 【取消当前未完成选区或拉伸】。
- 【点击已完成操作并删除】 -> 【删除该拉伸操作并恢复其覆盖区域】。

#### 7.6.4 异常与边界

- 选区宽或高小于画布显示尺寸的 2% 时，系统提示“选区过小，请重新选择”。
- 选区没有覆盖已有画面时，系统提示“请在图片内容中选择需要拉伸的区域”。
- 目标方向没有空白时，不显示对应手柄。
- 拉伸到画布边界后停止继续扩大。

### 7.7 AI 补全

#### 7.7.1 位置与目标

- 位置：图片适配 - 当前图片 - 固定画布 - AI 补全。
- 目标：使用当前完整画布补齐复杂背景。

#### 7.7.2 字段规则

- AI 模型：必选，默认使用最近一次成功使用的图片编辑模型。
- 生成清晰度：必选，候选值由模型能力决定，默认使用该模型最近一次成功提交的清晰度。
- 提示词：必填，最多 1000 个字符。
- 系统默认预填“延续现有画面的背景、光线、透视与纹理，只补全空白区域，保持人物、服装、比例和原有画面不变”的本地化提示词。
- 用户可以修改默认提示词；提示词为空时，“开始补全”不可点击并展示必填提示。
- 每次打开弹窗时提示词都恢复为本地化默认值，不读取上一张图片或上一次提交的提示词。
- AI 模型与生成清晰度必须使用 Lumina 统一的 `UiSelect` 组件，不得使用浏览器原生选择器样式。

#### 7.7.3 提交确认弹窗

- 弹窗标题为“确认 AI 补全”。
- 弹窗展示当前完整画布缩略图。
- 弹窗展示“AI 将读取整张画布，并只生成当前空白区域”。
- 弹窗展示所选模型、清晰度和服务商费用说明。
- 主按钮为“开始补全”，次按钮为“取消”。
- 点击遮罩层不关闭弹窗。

#### 7.7.4 处理与结果

- 【点击“开始补全”】 -> 【关闭弹窗，当前图片进入 AI 补全中】。
- 【AI 补全中】 -> 【画布展示进度状态，编辑控件置灰】。
- 【AI 补全中点击“处理下一张”】 -> 【选择完整列表中严格相邻的下一张，当前任务继续后台运行】。
- 【AI 返回成功】 -> 【AI 结果自动成为当前固定画布结果并恢复可导出状态】。
- 【提交中或 AI 补全中点击取消】 -> 【立即恢复提交前完整画布，停止本地轮询并忽略迟到结果】。

#### 7.7.5 异常与边界

- 模型不可用时提示“当前模型不可用，请更换模型后重试”。
- 服务商拒绝请求时展示服务商返回的可读原因。
- 任务中断时保留当前构图和拉伸操作。
- 用户查看其他图片不停止当前 AI 任务。
- 同一批次允许多张图片同时运行 AI 任务，各任务独立更新为生成中、已生成或生成失败。
- “处理下一张”不跳过任何图片状态，当前图片为最后一张时按钮置灰。
- 用户返回正在处理的图片时继续展示任务状态。
- 本地取消不承诺终止服务商任务；取消入口和反馈必须说明任务可能继续执行并产生费用。

### 7.8 批量导出

#### 7.8.1 位置与目标

- 位置：图片适配 - 工作台左栏底部 - 批量导出。
- 目标：导出所有具备结果的图片。

#### 7.8.2 导出前规则

- 按钮展示可导出图片数量。
- AI 补全中的图片暂不计入可导出数量；取消后提交前结果立即恢复计数。
- 没有可导出图片时按钮置灰。
- 点击后展示可导出数量、跳过数量和输出目录。

#### 7.8.3 导出结果

- 【确认导出】 -> 【按图片当前构图方式生成文件】。
- 【部分成功】 -> 【展示成功和失败数量，允许重试失败项】。
- 【全部成功】 -> 【展示输出目录和“确认”“添加新批次”】。
- 【点击“确认”或关闭弹窗】 -> 【保留当前图片和结果】。
- 【点击“添加新批次”】 -> 【清空当前图片和缓存，保留输出尺寸】。

## 8. 非功能需求

### 8.1 性能

#### 8.1.1 NFR 展开

- NFR-1：拖动、缩放和拉伸的目标预览帧率为 30 帧每秒以上。
- NFR-2：交互过程中只更新内存预览，操作结束后再合并保存状态。
- NFR-3：预览图最长边不超过 2560 像素，最终本地结果读取原图。

### 8.2 隐私与安全

## 11. 技术说明交接

### 11.1 业务对象与关键字段口径

#### 11.1.1 对象清单

| 对象 | 关键字段 | 是否允许为空 | 来源 |
|---|---|---:|---|
| 适配批次 | 输出尺寸、图片列表、导出目录 | 否 | 用户选择 |
| 图片项 | 文件信息、当前构图方式、状态 | 否 | 导入与用户操作 |
| 裁剪草稿 | 裁剪区域、旋转状态、确认状态 | 是 | 裁剪填满编辑 |
| 固定画布草稿 | 缩放、位置、构图确认状态 | 是 | 固定画布编辑 |
| 拉伸操作 | 来源矩形、目标方向、目标范围、顺序 | 是 | 区域拉伸 |
| AI 补全任务 | 模型、清晰度、提示词、任务状态 | 是 | 用户提交 |
| AI 结果 | 结果图片、生效状态、错误信息 | 是 | 模型服务商 |
| AI 补全偏好 | 最近成功提交的模型、清晰度 | 是 | 本地持久设置 |

### 11.2 状态与操作矩阵

#### 11.2.1 状态矩阵

| 状态 | 切换构图方式 | 调整构图 | 区域拉伸 | AI 补全 | 导出当前结果 |
|---|---:|---:|---:|---:|---:|
| 待确认 | 是 | 是 | 否 | 否 | 否 |
| 调整构图 | 是 | 是 | 否 | 否 | 否 |
| 区域拉伸 | 是 | 需返回调整 | 是 | 有空白时是 | 是 |
| AI 补全中 | 否 | 否 | 否 | 否 | 否 |
| 可导出 | 是 | 是 | 固定画布时是 | 有空白时是 | 是 |
| 导出中 | 否 | 否 | 否 | 否 | 否 |
| 已导出 | 是 | 是 | 固定画布时是 | 有空白时是 | 是 |

### 11.3 动作矩阵

#### 11.3.1 核心动作

| 动作 | 前置条件 | 成功反馈 | 失败反馈 | 是否覆盖旧数据 |
|---|---|---|---|---:|
| 切换构图方式 | 当前图片不在处理中 | 恢复目标方式草稿 | 保持当前方式并提示原因 | 否 |
| 确认构图 | 固定画布可编辑 | 进入空白处理并立即可导出 | 保持构图并提示原因 | 更新确认状态 |
| 完成区域拉伸 | 选区和方向有效 | 新增拉伸操作 | 取消无效操作并提示 | 否 |
| 开始 AI 补全 | 已确认构图且存在空白 | 进入处理状态 | 保留提交前画布 | 否 |
| AI 返回成功 | AI 结果可用且任务未取消 | 自动成为当前结果并可导出 | 保留提交前画布并提示 | 是 |
| 取消 AI | 正在提交或生成 | 恢复提交前画布并忽略迟到结果 | 保持当前画布 | 否 |
| 改变输出尺寸 | 用户确认重置 | 全批次使用新尺寸 | 保持原尺寸 | 是 |
| 批量导出 | 至少一张可导出 | 展示导出结果 | 展示失败项 | 不覆盖原文件 |

### 11.4 最终口径

#### 11.4.1 数据真相源

- 批次输出尺寸是所有图片最终像素尺寸的唯一口径。
- 单张图片当前构图方式是该图片导出结果的唯一口径。
- 固定画布中记录的几何空白是区域拉伸和 AI 补全范围的唯一口径。
- 已生效的 AI 结果只属于提交时的固定画布构图。
- 用户改变该构图后，旧 AI 结果不能继续作为当前结果。
