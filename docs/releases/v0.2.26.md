## 新增

- 新增批量图片固定画布构图、区域拉伸、AI 补全与混合导出流程。
- 新增固定画布本地渲染与 JPEG 导出命令，并增加尺寸、变换和输出路径校验。
- 新增 Canvas Agent 批量导入图片、批量运行节点和紧凑进度等待能力。

## 优化

- 优化批量图片工作台的单图构图状态、预览、结果审核和中断恢复流程。
- 优化 Canvas Agent 的画布修订校验、变更结果轮询和生成节点命名。
- 优化批量图片、Canvas Agent 与相关画布状态的测试覆盖和中英文文案。

## 修复

- 修复批量图片固定画布渲染和导出过程中无效输入可能导致结果异常的问题。
- 修复 Canvas Agent 变更与节点进度状态在画布修订变化后可能失真的问题。
