# 高质量 AI 电商模特图生成调研

日期：2026-08-15

状态：提示词与生成策略建议，不包含图片生成或产品代码改动

## 1. 结论摘要

当前这类“蜡质皮肤、假人姿态、均匀暖光、样板间木质背景”的问题，不能只靠增加“高清、专业、大片、8K、电影感”等质量形容词解决。OpenAI 的官方建议恰好相反：自然写实应按“一张真实照片正在某个普通瞬间被拍下”来描述，明确要求真实皮肤和织物质感，并避免暗示棚拍抛光、重度布景或重修的措辞。[S1]

建议把任务拆成两组约束：

1. **商品与身份事实必须锁定**：模特脸部、肤色、发型、身形比例，以及毛衣的颜色、领型、肩线、袖长、下摆、罗纹、针法、纱线粗细和整体松量，都从参考图继承，不允许模型自行“优化”。OpenAI 的虚拟试衣建议也是先锁定人物身份和身体属性，只让服装发生指定变化，并要求真实垂坠、褶皱、遮挡、光照和阴影。[S1]
2. **摄影与场景变量逐张改变**：每次只确定一个画面目标、一个主要动作、一个视线方向和一个主光源。OpenAI 建议明确人物取景、尺度、姿势、视线与物体交互，并通过小步单变量迭代减少漂移。[S1]
3. **暖意来自材质和生活痕迹，不来自全画面橙色滤镜**：木纹、旧木地板、棉麻沙发和少量日常物件可以提供温暖感；毛衣本身仍保持中性白平衡下的参考色。Canon 建议先用单一窗光和反光板，避免混合光源，并在位置变化后重设白平衡。[S3]
4. **真实皮肤不等于凭空增加身份特征**：可以要求毛孔、细小绒毛、唇纹、眼下轻微色差和局部不均匀，但不应添加参考图中没有的痣、雀斑、伤疤或年龄特征。前半句有 OpenAI 的真实纹理建议支持；后半句是为了身份准确性的本项目推导。[S1]
5. **真实毛衣不等于给新品增加起球和磨损**：应表现纱线纤维、针织起伏、重力褶皱、肘部弯曲和身体接触造成的自然压缩；参考图没有的起球、破损、抽丝或做旧会误导商品。Shopify 和 Google 都强调颜色、材质、细节、版型及商品变体要准确呈现。[S4][S5][S6]
6. **高分辨率不是第一优先级**：先在可靠尺寸上把身份、服装和摄影逻辑校准，再提高质量。OpenAI 将超过 2560x1440 总像素数（3,686,400 像素）的 `gpt-image-2` 输出视为实验范围，结果可能更不稳定；身份敏感、近景人物和细节密集的最终图应比较 `medium` 与 `high`，而不是默认用超大尺寸硬顶。[S2]

本报告用以下标记区分证据层级：

- **来源事实**：一手/官方页面明确陈述的内容。
- **针对当前失败图的推导**：把官方摄影或模型指南应用到当前“AI 味重”问题上的判断，不冒充官方结论。
- **经验性建议**：可执行但没有足够一手来源直接证明的提示词细节，必须通过 A/B 和人工验收确认。

## 2. 一手来源明确支持的事实

### 2.1 `gpt-image-2` 提示与编辑

OpenAI 官方提示指南支持以下做法：

- 提示词保持稳定顺序：`场景/背景 -> 主体 -> 关键细节 -> 约束`；复杂请求使用短段落或标签，不必依赖特殊语法。[S1]
- 写实照片要直接说明 `photorealistic`、`real photograph` 或 `taken on a real camera`，摄影参数主要用于控制观感与构图，精确镜头参数可能被宽松解释。[S1]
- 自然写实应像真实瞬间拍摄，明确要求毛孔、皱纹、织物磨耗或其他真实细节，避免棚拍抛光与重度布景措辞；细节重要时使用较高质量。[S1]
- 人物画面要明确身体取景、尺度、视线、姿势和物体交互，例如“全身含脚”“看向手中物体”“双手自然抓握”等。[S1]
- 编辑任务应明确写出“只改变 X，其他保持不变”，并在每轮迭代重复关键保留项，以减少身份、几何、色彩和构图漂移。[S1]
- 多图输入应按编号说明职责，例如“图片 1 是商品，图片 2 是风格参考”，再说明两者如何组合。[S1]
- 先用干净的基础提示，再做小而单一的后续变化，比一次塞入大量修改更容易定位失败原因。[S1]
- 虚拟试衣场景应锁定人物脸部、肤色、身体、发型、表情和比例，只替换服装，并要求衣物与身体几何匹配，具有真实垂坠、褶皱、遮挡、光照与阴影。[S1]
- 将人物放入新场景时，应锁定不能改变的人物属性，使用自然光、真实颜色和可信细节，并避免电影海报式灯光、强烈调色和风格化构图。[S1]

### 2.2 `gpt-image-2` 参数边界

OpenAI 当前 Image API 指南说明：[S2]

- `gpt-image-2` 对所有参考图片自动使用高输入保真度，调用时应省略 `input_fidelity`，不能通过该参数再提高。
- `quality` 支持 `low`、`medium`、`high` 和 `auto`；`low` 适合快速草稿，细节、身份和最终资产应比较 `medium` 或 `high`。
- 尺寸可以自定义，但两条边必须是 16 的倍数，长短边比不超过 3:1，总像素数在 655,360 到 8,294,400 之间。
- 超过 3,686,400 总像素的输出属于实验范围，稳定性可能降低。
- 模型仍可能在重复角色/品牌一致性和精确构图上失误，不能把“官方支持高保真输入”理解成“无需人工验收”。

### 2.3 真实人像的光线、颜色与姿态

Canon 的官方时尚摄影教程给出三点直接相关的经验：[S3]

- 先从一个光源和白色反光板开始；能用日光时优先用日光，不混用自然光与人工光。
- 窗光正面照向模特虽然均匀，但缺少体积；让模特相对窗户转约 30-45 度，会形成更能表现脸部形状的阴影和对比。
- 每次换地点应重新确认曝光和白平衡，避免偏暖、偏冷或多光源造成的颜色失真。
- 与其命令模特“放松”，不如从简单、自然的姿势开始，让动作逐步展开；Canon 受访摄影师认为这种节奏更容易出现自然表现。

这些内容支持“单一方向窗光、保留明暗层次、逐步建立动作”的摄影逻辑，但没有直接规定某一种腿部重心或手势。后文的具体重心和手部提示属于可验证的项目推导。

### 2.4 电商服装图的商品真实性

官方电商资料形成了较一致的要求：

- Shopify 建议用模特展示衣服如何贴合与垂坠；生活方式图应位于真实环境、使用自然光，让顾客看见日常条件下的颜色和纹理。[S4]
- Shopify 建议先做 shot list，至少覆盖正面、背面、侧面、细节近景和生活方式图；近景用于展示织物纹理、车线和独特细节。[S4]
- Shopify 将服装颜色校正的目标写为“确保准确”，并建议使用白平衡和最高质量原始文件保留细节。[S4]
- Canon 建议不混用自然光与人工光并校准白平衡；Shopify 建议让背景克制、服装保持清楚，生活方式图仍以商品为核心。[S3][S4]
- Google Merchant Center 建议服装由真人穿着展示，完整全身图不要切掉头或脚；若只售上装，应确保上装是画面焦点，并提供多角度和近景附图。[S5][S6]
- Google 要求商品图片匹配正确变体，并正确显示颜色、图案与材质；生活方式图可以使用，但商品仍需清楚可辨。[S6]

因此，电商图的“真实”不只是人物像真人，也必须让消费者能据图判断版型、颜色和材质。只提升皮肤写实而牺牲毛衣准确性，仍然是不合格结果。

## 4. 推荐的生成工作流

### 4.1 先定义参考图职责

每次请求固定写明：

- **图片 1：模特身份参考。** 只提供脸部、肤色、发际线、发型、体型和身体比例；不把图片 1 的原服装当作目标服装。
- **图片 2：毛衣商品参考。** 只提供目标毛衣的颜色、结构、针织纹理、材质观感、版型和细节；不从图片 2 继承人物身份。
- **可选图片 3：场景参考。** 只提供木质室内的空间关系、材质和光线方向；明确禁止继承其中的人物、服装、品牌标识和装饰品。

这是 OpenAI “按图片编号和职责描述多图输入”原则的直接应用。[S1]

**经验性建议：**第一轮只使用模特卡和毛衣两张关键参考。只有文字无法稳定表达空间时再加场景参考；参考越多，职责越要写窄，避免把场景图里的人物、家具或服装误当成需要复制的对象。

当前两张输入都是多视图拼版。正式 A/B 时，建议把模卡的正面全身、正脸和侧脸分别裁成独立参考，把毛衣正面与背面也按镜头需要分开：正面和细节镜头只提供毛衣正面，真正需要背面时再加入背面参考。这样每个图片编号只有一个明确职责。此项是针对当前输入结构的项目建议，本报告未执行裁切。

### 4.2 把“不可变事实”和“本张变量”分开

不可变事实应在每一张图、每一轮修订中重复：

- 模特：脸型、五官比例、肤色、发际线、发型、年龄感、体型、肩宽和整体比例。
- 毛衣：实际颜色、领型、肩线、袖长、袖口、下摆、罗纹宽度、针法分布、纱线粗细、图案、标识和整体松量。
- 禁止：美颜改变五官、拉长身材、改变肤色、重新设计毛衣、添加配饰或标识。

本张变量只写：

- 景别与机位；
- 一个姿态和主要动作；
- 一个视线方向；
- 场景和光线方向。

### 4.3 皮肤：要求“可感知的真实微纹理”，不要要求“随机瑕疵”

推荐描述：

> 保留与图片 1 一致的肤色和身份特征。皮肤呈未经美容修饰的真实相机质感，可见自然毛孔、细小面部绒毛、唇纹、眼下轻微色差和局部不均匀；高光随面部曲面自然变化，不是均匀塑料反光。不要添加参考图中没有的痣、雀斑、伤疤或年龄特征。

OpenAI 明确支持“毛孔、皱纹、真实质感、无重度修饰”；“不新增身份特征”是身份锁定原则在本任务上的推导。[S1]

不建议使用：

- `perfect skin`、`flawless skin`、`porcelain skin`；
- `beauty campaign`、`luxury studio portrait`；
- `ultra smooth`、`airbrushed`；
- 只写笼统的 `no AI look`，却不指出具体要消除的蜡质高光、磨皮和均匀纹理。

### 4.4 姿态：写清“重心、支撑、双手、视线”

OpenAI 的来源事实是要明确取景、姿势、视线和物体交互；以下四字段是可执行的项目化写法：[S1]

1. **重心**：重量在哪条腿、是否坐稳、身体是否轻微前倾。
2. **支撑**：脚落地、手指触椅背、前臂搭大腿或身体靠沙发的具体接触关系。
3. **双手**：两只手分别做什么，只保留一个主动动作。
4. **视线**：看镜头外、看窗外、看袖口或看手中物体，避免所有图都直视镜头。

经验性建议：身体姿态可以不对称，但商品结构不能因此被遮挡。正面主图优先完整显示领口、胸前针法和下摆；生活方式图再允许手臂弯曲和身体接触产生真实褶皱。

### 4.5 木质暖室内：让空间“有生活功能”，不要“全新成套”

推荐结构：

- 普通住宅中的阅读角、餐桌一侧或窗边沙发，不写“豪华会所、精品酒店、设计师样板间”。
- 单一侧窗柔光；木材负责暖色感，白平衡仍保持毛衣颜色准确。
- 背景仅放 2-3 个与空间功能有关的物件，例如翻开的书、使用过的陶杯、略有褶皱的棉麻毯；不把道具堆成陈列柜。
- 木地板、椅背或桌沿可有轻微正常使用痕迹，家具不必完全同色同系列，构图不做镜像对称。
- 背景清楚到足以证明是真实空间，但不过度虚化成纯色光斑，也不抢走毛衣焦点。

“真实环境、自然光、商品仍是主角”有 Shopify 和 Google 的官方支持；具体生活痕迹与非对称物件是针对样板间感的推导，需要用结果验收。[S4][S6]

### 4.6 毛衣：保留商品结构，增加物理可信度

推荐同时写入两类要求：

- **结构不变**：颜色、领型、肩线、袖长、袖口、下摆、罗纹、针法、纱线粗细和松量与图片 2 一致。
- **物理合理**：布料受重力自然下垂，在腋下、肘部、腰部和坐姿接触面形成与动作一致的褶皱、压缩、遮挡和接触阴影；不能像平面贴图悬浮在身体上。[S1]

禁止凭空增加图片 2 中不存在的起球、破损、污渍、抽丝、口袋、纽扣、图案、Logo 或饰品。若要表现微观质感，应写“可见真实纱线纤维和针织起伏”，而不是“明显磨损”。

## 5. 参数与迭代建议

### 5.1 Lumina 当前参数映射

仓库当前 `AI Media / gpt-image-2` 适配层有三项与本次 A/B 直接相关的事实，见 [`src-tauri/src/ai/providers/openai.rs`](../../src-tauri/src/ai/providers/openai.rs)：

- 界面选择 `2K` 时，请求尺寸按长边 `2048` 计算，同时发送 `quality=medium`。
- 界面选择 `4K` 时，请求尺寸按长边 `4096` 计算，同时发送 `quality=high`。
- 编辑请求没有发送 `input_fidelity`；这与当前 OpenAI 官方文档要求一致，因为 `gpt-image-2` 应省略该参数并自动以高输入保真度处理参考图。[S2]

这意味着当前界面把“输出尺寸”和“渲染质量”绑在同一个档位里，不能直接完成“同一可靠尺寸下只比较 `medium` 与 `high`”的干净实验。也不应仅为了得到 `quality=high` 就切到 `4K`：它同时改变两个变量，而且 `4096` 长边超过 OpenAI 官方 API 当前允许的 `3840` 上限。`AI Media` 属于兼容接口，第三方是否重映射或放宽尺寸需以实际请求和返回为准；本报告不把官方 API 行为自动外推为兼容接口保证。

### 5.2 推荐参数基线

| 项目 | 建议 | 依据与边界 |
| --- | --- | --- |
| 模型 | `gpt-image-2` | 官方将其用于高质量生成、编辑、合成和身份敏感任务 [S1][S2] |
| 调用类型 | 图像编辑，多参考图 | 本任务需要继承模特身份与毛衣事实，不适合纯文本从零生成 [S1] |
| `input_fidelity` | 省略 | `gpt-image-2` 自动按高输入保真处理，官方 API 不允许调节 [S2] |
| 草稿质量 | `medium`；成本或速度敏感时先 `low` | `low` 适合快速草稿；身份与细节需比较更高质量 [S1][S2] |
| 最终质量 | `high` | 近景人像、身份与针织细节属于高保真敏感场景 [S1] |
| 4:5 草稿尺寸 | `1024x1280`，前提是当前供应商支持自定义尺寸 | 两边均为 16 的倍数，处于官方像素约束内；这是按官方规则计算出的项目建议 [S2] |
| 4:5 最终尺寸 | 优先 A/B `1536x1920` 与现有配置 | `1536x1920` 为 2,949,120 像素，低于官方实验边界；这是按官方规则计算出的项目建议 [S2] |
| Lumina 现有 `2K` | 可用于构图和语义基准，但当前同时固定为 `quality=medium` | 已由本地适配层确认；最终仍需在相同尺寸下单独比较 `high` |
| 单次目标 | 一次只生成一个镜头目标 | 便于发现身份、商品、姿态或场景是哪一层漂移 [S1] |
| 输出格式 | 评审母版优先 PNG | 避免 JPEG 压缩干扰皮肤和纱线微纹理判断；格式不会修复语义错误 [S2] |

`1536x1920` 不是 OpenAI 页面列出的“热门尺寸”，但满足其当前全部自定义尺寸约束。若 Lumina 当前供应商只接受预设档位，应优先验证供应商实际请求与返回尺寸，不能仅按界面上的“2K”名称推断。

### 5.3 推荐迭代顺序

1. **先做正面/三分之二身基准图**：只校准身份、毛衣结构、肤质和单窗光，不先加入复杂动作。
2. **每轮只修一个最高优先级问题**：例如只修“恢复参考毛衣的领口与罗纹”，不要同时换场景、姿势和色温。[S1]
3. **基准通过后冻结不可变段**：后续四张都复用同一身份与商品约束，只替换镜头段。
4. **再做动作图、坐姿图和细节图**：每张独立请求，不在一条提示中要求模型同时理解四格分镜。经验性建议是把通过验收的基准图作为后续镜头的可选图片 3，只锁定同一轮拍摄的妆发、穿搭和色调；图片 1 仍是身份事实源，图片 2 仍是毛衣商品事实源，基准图中的商品错误不得被继续继承。
5. **最后才提高尺寸或质量**：提示词、参考图和构图不变，只改变一个参数做 A/B。
6. **漂移时回到最近一次通过的基准**：OpenAI 明确建议在每轮重复关键保留项，不能用“跟上一张一样”替代商品和身份事实。[S1]

## 6. 可直接用于 `gpt-image-2` 编辑的提示词结构

使用方式：每次请求发送“固定基础段 + 一个镜头段”。图片顺序固定为图片 1 模特卡、图片 2 毛衣商品图。不要把四个镜头段一次性合并。

### 6.1 固定基础段

```text
任务类型
使用两张参考图完成一次多参考图图像编辑，生成一张真实相机拍摄的电商服装照片。不是插画，不是 3D 渲染，不是电影海报，也不是重度美容广告。

参考图职责
- 图片 1 是唯一的模特身份参考：保留她的脸型、五官比例、肤色、发际线、发型、年龄感、体型、肩宽和身体比例。不要美化或重新设计她的脸和身材。
- 图片 1 只提供身份事实，不继承其中的灰色棚拍背景、原服装、均匀磨皮或合成质感。
- 图片 2 是唯一的毛衣商品参考：左侧是正面，右侧是背面；准确保留毛衣的实际颜色、领型、肩线、袖长、袖口、下摆、罗纹宽度、针法分布、纱线粗细、图案和整体松量。

系列穿搭
四张图固定搭配浅蓝水洗直筒牛仔裤和无 Logo 的米白色简洁低帮鞋，不改变裤型、颜色或鞋型，不添加首饰、腰带、帽子、包或其他配饰。

真实质感
皮肤呈未经美容修饰的真实相机质感，可见自然毛孔、细小面部绒毛、唇纹、眼下轻微色差和局部不均匀；高光随面部曲面自然变化。不要添加参考图中没有的痣、雀斑、伤疤或年龄特征。
毛衣可见真实纱线纤维和针织起伏；布料受重力自然下垂，并在腋下、肘部、腰部和接触面形成与姿态一致的褶皱、压缩、遮挡和接触阴影。不要增加图片 2 中没有的起球、破损、抽丝、污渍、口袋、纽扣、图案、Logo 或饰品。

摄影与光线
像真实摄影师在普通生活瞬间拍到的照片，眼平视角，自然透视，不使用夸张广角。只使用一扇侧窗作为主要光源，光线方向明确，离窗一侧自然变暗，保留真实阴影层次和接触阴影。白平衡中性，木材可以显得温暖，但毛衣颜色必须与图片 2 一致。

场景原则
普通、有人真实生活的木质住宅空间，简洁但不是样板间。家具不完全成套，摆放不镜像对称，只出现少量与空间功能有关的日常物件和轻微正常使用痕迹。背景服务于商品，不遮挡或抢夺毛衣焦点。

禁止项
不要蜡质或塑料皮肤，不要磨皮、美颜、瓷娃娃肤质、均匀高光、HDR tone mapping、电影调色、全画面橙色滤镜、多方向影棚补光、过度背景虚化、假人式对称站姿、僵硬手指、额外或融合的手指、拉长肢体、改变身份、改变毛衣结构或颜色。
```

### 6.2 镜头 A：正面全身商品主图

本张镜头
竖幅 4:5，全身入镜，头和双脚完整可见，眼平视角，毛衣是画面中心且领口、胸前针法、袖口和下摆都清楚。
模特站在窗边木地板上，身体略微转开但毛衣正面仍完整可见。重心明确落在右腿，左脚自然向前半步，左膝放松。右臂自然垂下，左手指尖轻触一把旧木椅的椅背，不遮挡毛衣。她看向镜头旁边而不是直盯镜头，表情平静、自然，没有广告式夸张微笑。

## 7. 人工验收清单

生成结果至少以 100% 尺寸检查一次。以下为项目验收建议，不是官方 API 保证：

| 维度 | 通过标准 | 失败即处理 |
| --- | --- | --- |
| 模特身份 | 脸型、五官比例、发际线、肤色、发型、年龄感与图片 1 一致 | 身份明显漂移则整张淘汰，不用“后期磨回来” |
| 皮肤 | 微纹理有空间变化，鼻翼、脸颊、唇部和眼下不是同一种平滑材质 | 蜡质高光、瓷娃娃肤质、全脸统一噪点则单变量修订 |
| 手部与人体 | 手指数量、关节、抓握/接触关系合理，脚与地面或身体与沙发有真实承重 | 融合手指、漂浮手、无承重姿态则淘汰或只修姿态 |
| 毛衣结构 | 领口、肩线、袖口、下摆、罗纹、针法和松量与图片 2 一致 | 任一销售关键结构被重设计则淘汰 |
| 毛衣颜色 | 中性白平衡下与图片 2 一致，暖木背景没有把商品染成橙色 | 偏色则只修白平衡/商品色，不同时换场景 |
| 毛衣物理 | 重力、弯肘、坐姿和接触面产生相互一致的褶皱、遮挡与阴影 | 贴图感、漂浮布料、无接触阴影则只修布料物理 |
| 光线 | 人脸、毛衣、家具和地面的主光方向一致，有自然曝光衰减 | 多方向轮廓光、阴影方向冲突、HDR 暗部抬平则淘汰 |
| 场景 | 能判断为真实住宅功能空间，背景克制、非对称、有少量生活痕迹 | 样板间、酒店大堂、全新成套家具或装饰过多则只修背景 |
| 电商可用性 | 商品是清晰主角，至少一张展示完整版型，另有角度和细节图 | 道具、手臂或裁切妨碍判断商品则重做该镜头 [S4][S5][S6] |

建议把“身份、商品结构、商品颜色、手部”设为硬门槛；任何一项失败都不进入后期修图。肤质、场景和姿态可通过单变量修订继续迭代。

## 8. 风险与边界

- **参考图信息上限**：如果模特卡本身分辨率低或已经重度磨皮，模型只能补出“可信的皮肤微纹理”，不能还原参考图中不存在的真实毛孔数据。这是生成推断，不是身份事实。
- **服装真实性上限**：单张毛衣图看不到背面、侧缝、内里或精确纱线成分时，模型无法可靠推断这些结构。销售关键细节应补充相应角度参考，而不是让提示词猜测。
- **一致性不是保证**：OpenAI 明确列出角色和品牌元素在多次生成中仍可能不一致，系列图必须逐张验收。[S2]
- **精确镜头参数不是物理模拟**：焦段、光圈等词主要控制视觉感受；不要把“50mm、f/2.8”当作几何正确性的保证。[S1]
- **暖光与颜色准确存在张力**：室内可通过木材和局部灯具显得温暖，但商品区域应维持中性、可比较的颜色；Google 和 Shopify 都把正确颜色/变体视为商品事实。[S4][S5][S6]
- **平台披露要求**：若这些图用于 Google Merchant Center，Google 当前要求生成式 AI 图片保留表示 AI 生成/合成来源的 IPTC 元数据，不应在导出链路中移除。[S6]
- **本报告未执行图片生成**：所有尺寸、质量和提示词建议都需要在 Lumina 当前实际供应商链路中做 A/B，不能把官方 OpenAI API 行为自动等同于第三方兼容接口行为。
